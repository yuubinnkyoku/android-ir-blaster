# DP-700SH 調査追補 — 2026-09-09 15:23 JST

## 新しい根拠: 2010年発表時の3機種それぞれに同一外観の専用リモコンが掲載

### 確認できた事実

2010-02-03付のRBB TODAY記事には、FUJIFILMが同時発表した `DP-1020SH` / `DP-850SH` / `DP-700SH` について、機種ごとの製品写真が3枚残っている。各画像ページのキャプションは明示的に次のようになっている。

- 1/3: `DP-1020SHの本体正面・背面とリモコン`
- 2/3: `DP-850SHのカラバリ・本体正面・背面とリモコン`
- 3/3: `DP-700SHのカラバリ・本体正面・背面とリモコン`

3枚に写るリモコン前面は、外形、赤い電源ボタン、方向/決定キー、および下段の機能ボタン配置まで同一に見える。記事本文も3製品の付属品として `専用リモコン` を挙げている。

- DP-850SH画像: https://www.rbbtoday.com/article/img/2010/02/03/65433/94806.html
- DP-700SH画像: https://www.rbbtoday.com/article/img/2010/02/03/65433/94807.html
- 記事本文: https://www.rbbtoday.com/article/2010/02/03/65433.html

既存の直接証拠として、DP-700SH一式の中古実物写真では、この外観のリモコン裏面ラベルを読めており `RRMCG2009SCZZ` と確定済み。また中古流通には `RRMCG2009SCZZ` をDP-850SH / DP-1020SH対応として扱う記録が複数存在する。

### 確定事項

- 2010年の発表時資料で、DP-700SH / DP-850SH / DP-1020SHの3機種すべてに、同一外観・同一キー配置に見える専用リモコンが組み合わされている。
- DP-700SHに写る同外観リモコンの実物型番は、別の裏面写真から `RRMCG2009SCZZ` と確定済み。

### 状況証拠 / 推測

この発表時写真と中古流通上の互換表記を合わせると、3機種でリモコンの筐体・キー配列だけでなく、同じ送信コード体系、さらに `RRMCG2009SCZZ` 自体を共用した可能性が従来より強くなる。3機種のUI/入力処理が共通基盤から派生したという見方とも整合する。

特に赤外線コード探索では、DP-700SH用コードが得られればDP-850SH / DP-1020SHでも同じコードが通る可能性を優先検証してよい。

### 断定しない点

- RBB TODAYの写真はリモコン前面だけで、DP-850SH / DP-1020SH側の裏面型番は読めない。したがって **3機種すべての正式リモコン型番が `RRMCG2009SCZZ` だったとはまだ確定しない**。
- 外観・キー配置が同じでも、内部の送信ICやデバイスアドレスが異なる可能性は理論上残る。
- `RRMCG2009SCZZ` がSharp 13-bit方式を使う証拠にはならない。生波形またはサービス資料による確認が必要。
