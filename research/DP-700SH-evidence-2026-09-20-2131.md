# DP-700SH 調査追加証拠 — 2026-09-20 21:31 JST

## 確定度: 高 — DP-700SH と DP-850SH は同一外観・同一キー配列のリモコンを使用

2010年2月3日の RBB TODAY の製品写真には、DP-700SH と DP-850SH それぞれについて本体正面・背面と付属リモコンが写っている。さらに中古実機写真でも両機種の付属リモコンを確認できる。

DP-700SH のリモコンは、上から `メニュー / ▲ / 電源`、`◀ / 決定 / ▶`、`戻る / ▼`、`スライドショー / インデックス / モード切替`、`便利メニュー / 時計 / 絞り込み`、`縮小 / 拡大 / 回転` の18キー構成。

DP-850SH の実機付属リモコン写真も、筐体形状、FUJIFILMロゴ、18キーの位置・日本語表記まで一致する。少なくとも外観上は同一部品と判断できる。

## 推測 — 3機種のIRコマンド体系も共通である可能性が高い

DP-700SHとDP-850SHでリモコンの筐体・全18キー表記・配置が一致し、DP-1020SHにも同型に見えるリモコンが付属する。3機種は同時期に同一シリーズとして発売され、2010-04-30のファーム更新内容も3機種共通（IrSimple/IrSS/IrDAのイレギュラー操作時ハング修正）だった。

したがって、少なくとも共通キーについてはIRプロトコル/アドレス/コマンドを共有する可能性が高い。ただし、外観一致だけでは送信コード一致を証明できない。`RRMCG2009SCZZ` の背面型番をDP-850SH/DP-1020SH付属品で確認するか、各機種で同一リモコンの相互操作を確認する必要がある。

## 逆解析への意味

`RRMCG2009SCZZ` のコード探索をDP-700SHだけに限定する必要は薄くなった。DP-850SH/DP-1020SHの中古付属リモコン、学習リモコンデータ、LIRC/IRDB投稿、修理部品表も同じ探索対象にできる。特にDP-850SH/DP-1020SHの取説・部品表でリモコン部品番号が取れれば、`RRMCG2009SCZZ` の対応機種範囲を直接確定できる。
