# DP-700SH 調査追加証拠 — 2026-09-19 08:55 JST

## 新規根拠: 直系前機種 DP-70SH の隠しファーム更新画面呼び出し手順

### 確定事項

デジカメ Watch の2009-04-01記事は、FUJIFILM DP-70SH の公式 Ver.1.04.00 更新について、通常メニューから直接更新するのではなく、以下の隠し操作で「ファームウェア書き換え画面」に切り替えると具体的に記録している。

1. フォーマット済みSDカードにファームウェアを保存
2. `設定メニュー` → `本体情報の表示` → `バージョン表示` を表示
3. 純正リモコンで **`拡大` → `縮小` → `時計` → `回転`** の順に押す
4. ファームウェア書き換え画面へ遷移

出典:
- デジカメ Watch, 2009-04-01「富士フイルム、7型デジタルフォトフレームのファームウェアを公開」
  - https://dc.watch.impress.co.jp/cda/accessories/2009/04/01/10602.html
  - 記事中の旧公式ダウンロードURL: http://fujifilm.jp/support/printer/download/digitalphotoframe/dp70sh/download001.html

DP-70SH は2009年発売のFUJIFILM初代7型機で、DP-700SHは2010年発表時に「従来機種 DP-70SH の流れを汲む7型」と報じられている。

補助出典:
- デジカメ Watch, 2010-02-02
  - https://dc.watch.impress.co.jp/docs/news/346441.html

### DP-700SHへの意味 — 状況証拠 / 検証候補

DP-700SHでも実機の `各種設定／本体情報の表示` にバージョン表示が存在することは既に確認済みで、手元個体は Ver.1.03.00。したがって、DP-70SHと同じ **`拡大 → 縮小 → 時計 → 回転`** がDP-700SHのファーム書き換え画面を呼び出すサービス操作として継承されているか、実機で検証する価値が高い。

この操作が継承されていれば、未回収の `TH34_dpf.pkg` を入手した際の公式更新経路だけでなく、ブートローダ/更新器の世代間共通性を調べる手掛かりになる。

### 推測と断定禁止

- **未確認:** DP-700SHで同じ4キー列が有効かどうか。
- **未確認:** DP-850SH / DP-1020SHでも同じキー列かどうか。
- **未確認:** DP-70SHとDP-700SHの更新器、ブートローダ、SoC、OSが同一かどうか。
- このキー列がDP-70SHに存在することだけで、DP-700SHのソフトウェア基盤が同一とは断定しない。
