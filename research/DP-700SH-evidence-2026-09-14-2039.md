# DP-700SH 調査追補 — 2026-09-14 20:39 JST

## 新規根拠: 2009年のDP-70SHは2010年DP-700SH系の重要な前身候補

### 確定事項

FUJIFILM初のデジタルフォトフレーム `DP-70SH` は2009年3月発売。2010年の `DP-700SH` と比べると、少なくとも次の特徴が一致または強く近似する。

- 7型 800×480
- SHARP製 ASV液晶
- JPEG静止画中心
- CF / SD(SDHC) / MMC / Memory Stick / xD系の多カード対応
- IrSimple / IrSSによる画像受信
- 明るさセンサー
- リモコン付属
- FUJIFILM製品だが、利用者レビューでは「製造元もシャープ」と記録されている

DP-70SHの当時レビューでは、後継 `DP-700SH` と比較して、赤外線通信ポートの位置、SDスロット機構、フレーム幅などが変わったことまで具体的に記録されている。したがって、利用者側でもDP-700SHはDP-70SHの後継として認識されていた。

さらにDP-70SHには公式ファームウェア `Ver.1.04.00` が2009-03-31に公開されている。更新方法は、SDカードへファームを書き込み、設定メニューの「本体情報の表示」→「バージョン表示」中にリモコンで

`拡大 → 縮小 → 時計 → 回転`

の順に押してファームウェア書き換え画面へ入る方式だった。

DP-700SHの2010年公式更新版も `Ver.1.04.00`。番号が同じであること自体は共通コードの証拠ではないが、SHARP製ASV液晶・IrSimple・静止画中心という製品構成が連続しており、DP-70SH側の更新機構・リモコンコード・SoC/基板を調べる価値が高い。

### Waybackで今回確認したこと

DP-70SH公式ダウンロード領域はWaybackに保存がある。

- `http://fujifilm.jp/support/digitalphotoframe/download/dp70sh/`
  - 2010-01-30以降に複数保存
- `http://fujifilm.jp/support/digitalphotoframe/download/dp70sh/download002.html`
  - 2010-02-04 / 2010-02-05など計7保存を確認

Wayback取得APIは今回429で本文取得に失敗したため、DP-70SHの実ファームファイル名までは未回収。ただしダウンロード承諾後ページ `download002.html` 自体の保存が存在することは確定した。

### 推測

`DP-70SH (2009) → DP-700SH / DP-850SH / DP-1020SH (2010)` は、単にSHARP製液晶を使った別企画ではなく、SHARP側のデジタルフォトフレーム製品基盤を世代更新した系統である可能性がある。

この仮説が正しければ、DP-70SHから次が得られる可能性がある。

- 2010年機と同系統のSoC/SDK/OSの痕跡
- `TH34_dpf.pkg`以前のFUJIFILM/SHARP内部パッケージ命名規則
- リモコンのプロトコル/アドレスの世代継承
- Sharp側の基板設計・ODM企業を2010年機より1年前へ遡る手掛かり

### 断定禁止

- DP-70SHとDP-700SHが同じSoC、OS、メイン基板を使うとは未確認。
- 両機の `Ver.1.04.00` が同一ソフトウェア系列を意味するとは限らない。
- DP-70SHのリモコンと `RRMCG2009SCZZ` が同一または互換である証拠はまだない。
- DP-70SHの製造元Sharpについて、現時点で確認できたWeb根拠は利用者レビューであり、銘板写真など一次資料の直接確認は未達。
