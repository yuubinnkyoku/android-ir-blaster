# DP-700SH investigation log — 2026-09-09 02:42 JST

## 探索対象

- 公式ファームウェア `TH34_dpf.pkg` / `TH35_dpf.pkg` / `TH36_dpf.pkg`
- DP-700SH / DP-850SH / DP-1020SH の基板、SoC、OS
- `RRMCG2009SCZZ` のIRコード
- 3機種の共通設計
- Sharp / AIPTEK / SanJet周辺の開発・ODM手掛かり

## 今回の検索結果

### ファームウェア

`TH34_dpf.pkg`、`TH35_dpf.pkg`、`TH36_dpf.pkg` のファイル名自体と2010年共通修正記事は再確認したが、実バイナリ本体の新しい保存先は発見できず。

参考:
- https://dc.watch.impress.co.jp/docs/news/365704.html

### SoC / OS / 基板

DP-700SH、DP-850SH、DP-1020SHについて基板・分解・SoC刻印を日本語/英語で再検索したが、刻印が読める新規写真は見つからず。

Sharp同時期製品のT-Kernel/eCROS系、AIPTEK/SanJet系、Sunplus/Generalplus/Mars系SoC候補も再検索したが、DP-700SH系列へ直接結びつく新しい一次資料は得られず。

### リモコン

`RRMCG2009SCZZ` の現物流通記録は再確認したが、搬送波・プロトコル・デバイスアドレス・各キーコードの新しい記録なし。

参考:
- https://paypayfleamarket.yahoo.co.jp/item/g1043790009

### 電源系で矛盾する新しい流通記録

現行メルカリShopsで `EP-D82F` を `DP-700SH ・ DP-850SH W` 対応品として明示する出品を確認。

- `EP-D82F`: 5V 2A、プラグ外径約5.0 mm
- https://jp.mercari.com/shops/product/2JQohR4vzgoe47oRWMSxCk

同一販売業者は別出品で、手元実機でも確認済みの `EP-D72F` をDP-700SH向けとしている。

- `EP-D72F`: 5V 2A、プラグ外径約4.0 mm
- https://jp.mercari.com/shops/product/witsx6ex6bHgyj9pdEhooj

このため、標準同梱品としての `DP-700SH -> EP-D72F` という確定事項は維持しつつ、`EP-D82F` の互換性については第三者流通上の矛盾した証拠として保留する。4.0/5.0 mm表記が正しいなら単純互換は疑わしい。

### AIPTEK / SanJet

AIPTEK Monet系列の既知資料を再確認。2007年Monetは8型800x480、CF/SD/MMC/MS、USB host/device、動画・音声再生、5V電源を備える。2008年Monet BTはBluetooth OPPを追加。これらはSanJet分割以前のDPF開発能力の状況証拠だが、DP-700SH系列への直接流用を示す新規資料は見つからず。

参考:
- https://www.photoscala.de/2007/12/10/digitalbildrahmen-monet-von-aiptek/
- https://www.photoscala.de/2008/02/18/bluetooth-bilderrahmen-monet-bt-von-aiptek/

## 判定

今回の意味のある新情報は、`EP-D82F` をDP-700SHにも対応するとする現行流通記録。公式資料ではないため確定事項には昇格させないが、DP-700SH/DP-850SHの電源入力部共通性を調べる際の反証・確認対象として価値がある。
