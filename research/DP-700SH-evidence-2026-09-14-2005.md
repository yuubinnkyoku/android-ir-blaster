# DP-700SH evidence — 2026-09-14 20:05 JST

## 新規根拠: ITEに吸収された繪展科技（SMedia）は、2007年時点ですでにデジタルフォトフレーム向け専用チップを量産採用まで持ち込んでいた

### 確定事項

2007-05-29のCTIMES記事で、繪展科技（SMedia Technology）が創惟科技（Genesys Logic）と共同で**デジタルフォトフレーム向け完成ソリューション**を発表していたことを確認した。

繪展側のチップは **`3210`** と明記され、記事には次の機能が記載される。

- 2D graphics
- JPEG
- Motion JPEG
- MPEG-4
- MP3
- これらを支援するハードウェア加速
- JPEGは純ハードウェアデコード
- 2D graphics engineによるPC級の画面遷移効果

組み合わせるGenesys Logic `GL824` は、多機能カードリーダーとUSB 2.0 OTGを担当する。

記事はさらに、この設計を**複数顧客が採用済みで、2007年第3四半期に最終製品が市場投入予定**としている。

後者はGenesys LogicのGL824/GL824Cが、ESS・MagicPixel・**SMedia**など複数のマルチメディア制御ICと組み合わせてデジタルフォトフレーム、LCD TV、PMPへ使われていたと記載する。

### ITEへの技術継承を示す同時代資料

2009-01-01を基準日にITE Tech.（聯陽半導體）は繪展科技を含む3社を吸収した。

2010-01-18の新電子科技の記事では、ITE第二事業部総経理の黃勃為氏が、ITEの新しいDPF向けSoCについて次を説明している。

- 旧・繪展科技のgraphics技術資源を利用
- CPUとGPUを1チップに統合
- DPF向けに3D graphics accelerationを搭載
- ITEは台湾勢で初めてDPF向けSoCへ3D engineを導入したと説明

出典:
- 新電子科技, 2010-01-18, 「3D/聯網上身　數位相框規格升級」
  - https://www.mem.com.tw/3d-%E8%81%AF%E7%B6%B2%E4%B8%8A%E8%BA%AB%E3%80%80%E6%95%B8%E4%BD%8D%E7%9B%B8%E6%A1%86%E8%A6%8F%E6%A0%BC%E5%8D%87%E7%B4%9A/

この時期は、既知の台湾側 `FUJIFILM DP-850SH/DP-1020SH / Customer: Sharp` 開発案件（2009-10〜2010-02）と重なる。

## DPシリーズとの比較

DP-850SH / DP-1020SHの公式仕様は、静止画JPEGに加えて Motion JPEG (AVI)、MPEG-4 SP、MP3、WAV を再生する。

SMedia 3210の公表機能は **JPEG / Motion JPEG / MPEG-4 / MP3** で、このうち主要な動画・画像・音声形式がDP-850SH / DP-1020SHと一致する。

これは、ITE/SMedia系をSoC候補とする上で従来より具体的な一致である。

## 状況証拠 / 推測

- ITE候補は「2009年末にたまたまDPF用SoCを発表した会社」ではなく、吸収したSMediaが**少なくとも2007年から実際のDPF向けチップと完成ソリューションを出荷段階まで進めていた系譜**を持つ。
- SMedia 3210の対応形式がDP-850SH / DP-1020SHの主要な再生形式とかなり重なるため、ITE/SMedia由来のマルチメディア基盤を基板・ファームで照合する価値がさらに上がった。
- ITEが2009年末に出した `IT9834` / `IT9836` は、このSMedia技術を継承した次世代DPF SoC系列として考えるのが自然。ただし3210→IT9834/9836の直接の型番系譜資料は未回収。

## 断定禁止

- DP-700SH / DP-850SH / DP-1020SHに `SMedia 3210`、`IT9834`、`IT9836` が搭載された直接証拠はない。
- 対応メディア形式の一致だけでSoCを特定してはならない。2007〜2010年のDPF用SoCではJPEG/MJPEG/MPEG-4/MP3は一般的な機能でもある。
- SMedia 3210が外付けGL824を必要とした構成と、2009年末のITE統合SoCの構成は同一とは限らない。
- DP-700SHは動画・音声再生を省いた下位機種なので、上位2機種と同一SoCの機能を無効化したのか、別チップ/別構成なのかは未確定。

## 基板・ファーム照合キーの追加

基板写真を得た場合は従来の `ITE` / `IT9834` / `IT9836` に加えて、旧繪展/SMedia系の刻印や `3210` を確認する。

ファームウェアを回収できた場合は、文字列・ヘッダ・デコーダ名・SDK名として `ITE`, `SMedia`, `3210`, `IT9834`, `IT9836`, `GL824`, `Genesys` を検索する。
