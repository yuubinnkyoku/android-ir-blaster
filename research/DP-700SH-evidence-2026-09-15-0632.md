# DP-700SH 調査追補 — ITE IT9834/IT9836 の世代混同に注意

調査日: 2026-09-15 JST

## 今回確認できた事実

### 1. 2009年に ITE（聯陽半導體）は DPF 向け `IT9834` / `IT9836` を実際に発表している

CTIMES の聯陽半導體企業ページに、2009-12-07付で「聯陽推出專屬數位相框的3D圖形加速單晶片」という記事要約が残る。

要約には以下が明記されている。

- デジタルフォトフレーム専用の3Dマルチメディアチップ
- 型番: `IT9834` / `IT9836`
- 海外大手メーカーから指定採用を得た旨

出典:
- https://ctimes.com.tw/unit/show-tw.asp?U=HJK75843KMJRN-00BN&V=ORG

2010-01-18の新電子科技雜誌の記事も、ITEが旧SMedia（繪展科技）のグラフィックス技術を使い、DPF向けにCPU/GPUを統合した3D対応SoCを投入していたことを裏付ける。ただしこの記事本文では型番までは示されない。

出典:
- https://www.mem.com.tw/3d-%E8%81%AF%E7%B6%B2%E4%B8%8A%E8%BA%AB%E3%80%80%E6%95%B8%E4%BD%8D%E7%9B%B8%E6%A1%86%E8%A6%8F%E6%A0%BC%E5%8D%87%E7%B4%9A/

### 2. ITEが現在公開している同名 `IT9834` / `IT9836` は Dual RISC-V 500MHz 世代

ITE公式の2021年前後のSoC紹介資料では、`IT983x` 系の機能ブロックとして以下が明記されている。

- Dual CPU
- RISC-V 500MHz ×2
- JPEG CODEC
- Graphic Engine
- LCD Controller
- USB / SDIO / NOR / NAND Flash 等
- `IT9834` / `IT9836` の名称

出典（ITE公式）:
- https://soc.ite.com.tw/upload/2021_09_222/ITE%2ASoC%2Aof%2AAutomotive%2ASmart%2ADisplay_EN.pdf
- https://soc.itechina.cn/upload/2021_09_242/ITE%2ASoC%2Aof%2AHome%2AAppliances_CH.pdf

### 3. 2009年版IT9834/9836を現行RISC-V版の仕様で説明することはできない

RISC-V Internationalの公式沿革では、RISC-V ISAの開発開始は **2010年5月** とされている。したがって、2009-12-07に発表済みのDPF向け `IT9834` / `IT9836` が、2021年資料に載る Dual RISC-V 500MHz 構成そのものだった可能性は時系列上排除できる。

出典:
- https://riscv.org/about/

## 解釈

### 確定

- ITEは2009年末にDPF向けSoC `IT9834` / `IT9836` を発表していた。
- ITEは2021年前後にも同じ `IT9834` / `IT9836` 名を含むRISC-V系 `IT983x` 製品資料を公開している。
- 2009年版を現行RISC-V版のブロック図・CPU仕様で同一視することはできない。

### 推測 / 要追加検証

- ITEが型番 `IT9834` / `IT9836` を後年再利用した、または同一製品系列名を大幅刷新しながら継続した可能性がある。どちらかは未確定。
- DP-700SH / DP-850SH / DP-1020SHに2009年版ITE SoCが載る可能性自体は、今回の確認では否定されない。
- 逆に、現行資料にある `RISC-V 500MHz×2`、64/128Mb DDR、現行パッケージ仕様などを2010年FUJIFILM機のSoC推定根拠として使ってはいけない。

## DP-700SH調査への影響

ITE候補を検証する際の最重要点は、**2009年当時のIT9834/IT9836資料、チップ写真、パッケージ刻印、SDK/ファーム文字列を探すこと**。現行ITE資料との単純な仕様照合は停止する。

DP-70SH公式ファーム `TH180700.ver` に見つかっている `SHARP_PF100_PLATFORM`、Flash/タスク管理関連文字列と、2009年版ITE SDKを直接結ぶ証拠は今回も見つかっていない。

また、`TH34_dpf.pkg` / `TH35_dpf.pkg` / `TH36_dpf.pkg` 本体、SoC刻印付き基板写真、`RRMCG2009SCZZ` の生IRコードには今回新規の直接証拠なし。
