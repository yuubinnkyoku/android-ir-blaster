# DP-700SH 追加証拠 — 2026-09-04 06:32 JST

## DP-70SH の公式ファーム実ファイル名を回収

Wayback Machine に保存された FUJIFILM 公式 DP-70SH ファームウェア配布ページ `download002.html`（2010-02-04 保存）を確認した。

### 確定事項

公式ページには次が明記されている。

- 対象: `デジタルフォトフレーム DP-70SH`
- ファームウェア: **`TH180700.ver`**
- 容量: **1.9MB**
- HTTP直リンク: `http://download.fujifilm.co.jp/pub/tools/dp70sh/TH180700.ver`
- FTP直リンク: `ftp://download.fujifilm.co.jp/pub/tools/dp70sh/TH180700.ver`

同じ時期の公式 `download001.html`（2010-01-30 保存）では公開最新版が **Ver.1.07.00** と明記され、Ver.1.04.00 → Ver.1.06.00 → Ver.1.07.00 の更新履歴も残る。

出典:
- https://web.archive.org/web/20100204003717id_/http://fujifilm.jp/support/digitalphotoframe/download/dp70sh/download002.html
- https://web.archive.org/web/20100130172650id_/http://fujifilm.jp/support/digitalphotoframe/download/dp70sh/download001.html
- https://dc.watch.impress.co.jp/cda/accessories/2009/04/01/10602.html

### 状況証拠 / 推測

DP-700SH世代の既知公式ファイルは `TH34_dpf.pkg`、DP-850SHは `TH35_dpf.pkg`、DP-1020SHは `TH36_dpf.pkg`、後継DP-701SH/DP-801SHは `TH50_dpf.pkg`。今回、先代DP-70SHでも `TH18...` という接頭辞が公式ファームに使われていたことが確認できた。

このため、`TH34/35/36/50` の `THxx` は単なる2010年3機種だけの便宜的なファイル名ではなく、少なくとも2009年DP-70SHから2011年DP-701SH/801SHまで続くFUJIFILM DPF系の内部プラットフォーム/案件/機種識別番号体系である可能性が高まった。

`TH180700.ver` は、末尾 `0700` が公式表示版 `1.07.00` と一致するように見える。したがって `TH18` が機種/プラットフォーム識別子、`0700` が版番号を埋め込んだ旧形式だった可能性がある。ただしファイル形式変更後の `TH34_dpf.pkg` では版番号がファイル名に出ないため、命名規則が途中で変更された可能性もある。

### 未確定

- `TH18` の18、`TH34/35/36/50` の番号そのものの意味
- `TH180700.ver` のバイナリ本体（Wayback CDXではHTTP直リンクの保存実体を確認できず）
- `.ver` と `.pkg` の内部形式の連続性
- `THxx` がSoC型番、基板番号、Sharp案件番号、FUJIFILM側製品管理番号のどれに由来するか

この発見はSoCを直接特定するものではないが、今後のファーム探索では `TH18`, `TH34`, `TH35`, `TH36`, `TH50` を同一系列の識別子候補として横断検索する価値が高い。
