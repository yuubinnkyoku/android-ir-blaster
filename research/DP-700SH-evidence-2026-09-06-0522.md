# DP-700SH 追加証拠 — 電源系（2026-09-06 05:22 JST）

## 確定度: 中（当時の実機利用者による切り分け）

### DP-700SHでSHARP製ACアダプター単体の初期不良報告

価格.comの2010-05-29投稿では、投稿者がDP-700SHを白・黒の2台同時購入し、黒個体でスタンバイランプが点灯しなかったため、白個体のACアダプターへ差し替えて切り分けている。白個体のACアダプターでは黒本体が起動したため、投稿者は黒個体付属のSHARP製ACアダプター不良と判断し、販売店へ交換依頼している。

この報告はメーカー一次資料ではないが、同型本体2台・ACアダプター2個を交換して症状が追従したという切り分けが具体的であり、DP-700SHの電源トラブルの少なくとも一部が本体基板ではなく外付けACアダプター側で起きていたことを示す。

出典:
- https://bbs.kakaku.com/bbs/K0000084345/ （「AC電源不良に注意」、2010-05-29）

## 確定度: 中〜高（流通個体の型番・寸法情報）

### DP-700SH用EP-D72FとDP-850SH系EP-D82Fは、近縁ATECH型番でもDCプラグ径が異なる流通記録

既知の純正ACアダプター:
- DP-700SH: SHARP `EP-D72F` / ATECH `T04A-05200D2-S2` / 5V 2A
- DP-850SH系で確認済み: SHARP `EP-D82F` / ATECH `T04A-05200D2-S3` / 5V 2A

中古流通情報では、EP-D72Fはプラグ外径約4.0mm、EP-D82Fは約5.0mmとして掲載されている。販売者計測値なのでメーカー仕様書より証拠力は低いが、少なくともS2/S3差が単なるラベル違いではなく、出力コネクタ形状など実機互換性に関わる差である可能性を高める。

出典:

- EP-D82F: https://jp.mercari.com/shops/product/2JQohR4vzgoe47oRWMSxCk

## 確定度: 高（当時報道によるメーカー発表引用）

### DP-1020SHは発売直前に「一部電源接続部の不具合」で発売延期

2010-03-10、FUJIFILMはDP-1020SHの発売日を3月13日から3月20日へ延期した。AV Watchはメーカー説明として「一部の機体に電源接続部の不具合があり、全数検査を行なうため」と報じている。一方DP-850SHは予定通り3月13日発売だった。

出典:
- https://av.watch.impress.co.jp/docs/news/353844.html

## 解釈 / 推測

- `EP-D72F / T04A-05200D2-S2` と `EP-D82F / T04A-05200D2-S3` は同じATECH 5V 2A系列だが、S2/S3の差にDCプラグ仕様が含まれる可能性がある。
- このため「DP-700SHとDP-850SHは電源までほぼ同一設計」という強い表現は避けるべき。より安全なのは「同じATECH電源系列を採用しているが、機種別のコネクタ/派生仕様がある」という整理。
- DP-1020SHの電源接続部不具合は、3機種の共通基板/共通電源を直接示すものではない。むしろDP-850SHが発売延期を受けていないため、少なくとも電源接続部にはDP-1020SH固有要素があった可能性もある。

## 断定禁止

- DP-700SH / DP-850SH / DP-1020SHのメイン基板が異なる、とまでは言えない。
- EP-D82FがDP-700SHの公式互換品とは確認できない。中古販売ページにはDP-700SH対応との記載があるが、別ページのプラグ径情報と食い違うため、販売者記載をそのまま公式互換認定として扱わない。
- DP-1020SHの「電源接続部」がACアダプター、DCジャック、本体基板上の電源回路のどれを指すかは公開情報から確定できない。
