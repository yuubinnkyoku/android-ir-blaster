# DP-700SH evidence update — 2026-09-16 13:30 JST

## 今回得られた新しい根拠

### 確定度: 高 — DP-700SH付属リモコンの背面型番を、本体とのセット出品写真で直接確認

Yahoo!オークションのDP-700SH本体・付属リモコンのセット写真で、リモコン背面ラベルを判読できる。

- `REMOTE CONTROL UNIT`
- `RRMCG2009SCZZ`
- `使用電池 リチウム電池 CR2025 1個`
- `FUJIFILM Corporation`

同じ出品の正面写真では、17キー構成（メニュー、方向/決定、戻る、スライドショー、インデックス、モード切替、便利メニュー、時計、絞り込み、縮小、拡大、回転）を確認できる。

出典:
- https://auctions.yahoo.co.jp/jp/auction/q1171811726

これは、単体リモコン販売記録だけでなく、**DP-700SH本体と一緒に写った個体の背面ラベルから `RRMCG2009SCZZ` を直接結び付ける証拠**になる。

### 確定度: 高 — DP-850SH / DP-1020SHの付属写真にもDP-700SHと同じ17キー外観のリモコンが写る

DP-850SHの中古実機写真では、DP-700SH用 `RRMCG2009SCZZ` と同じ17キー配置・同じ筐体外観のFUJIFILMリモコンが付属している。DP-850SH / DP-1020SH共通使用説明書と一緒に写った個体もある。

DP-1020SHの中古実機写真でも同じ17キー外観のリモコンが本体付属品として写る。また2010-02-03のRBB TODAY発表記事にはDP-1020SH / DP-850SH / DP-700SHそれぞれの本体とリモコンの製品写真が掲載されている。

## 状況証拠 / 推測

### DP-850SH / DP-1020SHも `RRMCG2009SCZZ` を共用していた可能性が高い

3機種の付属リモコンは正面のキー数・キー配置・筐体が一致して見える。さらにDP-700SH側では、その同一外観個体の背面ラベルが `RRMCG2009SCZZ` と直接読める。

したがって、2010年のDP-700SH / DP-850SH / DP-1020SHは同じリモコンを共用した可能性が高い。これは3機種の共通UI・同日共通ファーム修正と整合し、少なくとも**リモコン操作体系も共通基盤だった**という見方を補強する。

## 断定しないこと

- DP-850SHまたはDP-1020SHのリモコン背面ラベルそのものから `RRMCG2009SCZZ` を読める写真は、今回まだ回収できていない。
- よって「DP-850SH / DP-1020SHの純正リモコン型番も `RRMCG2009SCZZ`」は現段階では高確度推測であり、確定事項にはしない。
- 外観が同じでも内部の赤外線コードが同一とは限らない。生波形、搬送波周波数、アドレス、コマンド値は未回収。
- Sharp 13-bit方式であることも未確定。

## 次に強い証拠になるもの

1. DP-850SH / DP-1020SHとのセット出品で、リモコン背面 `RRMCG...` ラベルが読める写真。
2. `RRMCG2009SCZZ` 実機の全17キー生波形。
3. その波形をDP-700SH / DP-850SH / DP-1020SHへ送った相互動作確認。
