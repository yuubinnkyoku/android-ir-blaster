# DP-700SH 追加証拠 — 2026-09-04 14:18 JST

## 2010年発売時の製品写真で DP-700SH / DP-850SH / DP-1020SH のリモコン外観が共通

### 確定事項

2010-02-03 公開の RBB TODAY の発売記事・写真ページには、3機種それぞれについて「本体正面・背面とリモコン」が掲載されている。

- DP-1020SH: https://www.rbbtoday.com/article/2010/02/03/65433.html
  - 記事中の画像説明: `DP-1020SHの本体正面・背面とリモコン`
- DP-850SH: https://www.rbbtoday.com/article/img/2010/02/03/65433/94806.html
  - 画像説明: `DP-850SHのカラバリ・本体正面・背面とリモコン`
- DP-700SH: https://www.rbbtoday.com/article/img/2010/02/03/65433/94807.html
  - 画像説明: `DP-700SHのカラバリ・本体正面・背面とリモコン`

同記事本文は、3製品の付属品として `専用リモコン / ACアダプタ / スタンド` を挙げている。

写真を比較すると、3機種に写るリモコンは外形、赤い電源キーの位置、方向・決定キー、下段の機能キー群まで同じ配置に見える。少なくとも発売時点で3機種が同一外観のリモコンを使っていたことを示す、当時の製品写真ベースの強い状況証拠になる。

### 既知情報との結合

DP-700SH の実物付属リモコン裏面からは、型番 `RRMCG2009SCZZ` を直接確認済み。

したがって現時点では次のように整理する。

- **確定:** DP-700SH の純正リモコン型番は `RRMCG2009SCZZ`。
- **確定:** 2010年発売時の製品写真では DP-700SH / DP-850SH / DP-1020SH に同一外観・同一キー配置に見える専用リモコンが付属している。
- **かなり有力な推測:** DP-850SH / DP-1020SH も `RRMCG2009SCZZ` を共用していた。
- **未確定:** DP-850SH / DP-1020SH の付属リモコン裏面ラベルを直接読んで `RRMCG2009SCZZ` と確認すること。
- **未確定:** `RRMCG2009SCZZ` の赤外線プロトコル、アドレス、各キーの実コード。

### 意味

これまでの `DP-850SH / DP-1020SH 対応` とする中古流通記録だけでなく、発売時の同時代製品写真が加わった。3機種の UI / リモコン入力層が共通化されていたという仮説を補強するが、同一 SoC・同一メイン基板を直接証明するものではない。
