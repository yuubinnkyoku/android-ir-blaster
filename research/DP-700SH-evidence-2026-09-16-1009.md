# DP-700SH 調査追加証拠 — 2026-09-16 10:09 JST

## 新規根拠: 2009年のSharp製「デジタルフォトフレーム＋電話」機は eSOL eCROS / PrKERNELv4 を採用

### 確定事項

2009-10-20のイーソル公式プレスリリースで、Sharpが開発したインテリアホン `JD-7C1CL/CW` に、イーソルの組込みソフトウェア基盤 **eCROS** が採用されたことを確認した。

同製品は2009-09-25発売の、タッチパネル付き7型カラー液晶を持つコードレス電話機で、電話待機時にはSD/メモリースティックまたは本体保存写真をスライド表示する **デジタルフォトフレーム機能** を持つ。

イーソルの資料は、採用されたeCROSの構成を具体的に明記している。

- μITRON4.0仕様準拠RTOS: **PrKERNELv4**
- 開発ツール: **eBinder**
- ファイルシステム
- SDメモリーカード / メモリースティック等のメディアドライバ
- eSOLによるポーティング・カスタマイズ・受託開発を含むプロフェッショナルサービス

出典:
- eSOL公式（2009-10-20）: https://www.esol.co.jp/archive/news/emb_press091020.html
- PDF版: https://esol.co.jp/archive/news/emb_press091020.pdf
- JD-7C1CL発売時期の補助資料: https://review.kakaku.com/review/K0000053457/

### DP-70SH / DP-700SHへの意味 — 状況証拠

DP-70SHは2009年3月発売、DP-700SH系列は2010年2〜3月発売であり、JD-7C1CL/CWの開発・発売時期と重なる。また、DP-70SHの回収済み公式ファーム `TH180700.ver` には `TaskMgr`、`task switching..` などタスク型RTOSを示唆する文字列がある。

したがって、DP-70SH / DP-700SHのOS候補を調べる際、**eSOL eCROS / PrKERNELv4（μITRON4.0系）を優先照合候補に追加する価値がある**。特に `TH180700.ver` および将来回収できた `TH34_dpf.pkg` で、以下を探索する。

- `PrKERNEL`
- `eCROS`
- `eBinder`
- `ITRON`
- eSOL固有API名・エラー文字列・タスク管理シンボル

### 断定禁止

- JD-7C1CL/CWとDP-70SH / DP-700SHが同じOSを使った証拠はない。
- JD-7C1CL/CWは電話/FAX系機能を含む別製品であり、SoCや基板が共通とは限らない。
- `TaskMgr` / `task switching..` は一般的なRTOS実装でも現れ得るため、PrKERNELv4の直接証拠ではない。
- 現時点ではDP-70SH / DP-700SHのOS名は未確定のまま。

## 今回新規証拠なし

`TH34_dpf.pkg` / `TH35_dpf.pkg` / `TH36_dpf.pkg` 本体、`SHARP_PF100_PLATFORM` の別公開一致、SoC刻印付き基板写真、`RRMCG2009SCZZ` の生IR波形、ITE `IT9834/9836` とSharp/FUJIFILMを製品名付きで直接結ぶ資料については、新しい直接証拠を確認できなかった。
