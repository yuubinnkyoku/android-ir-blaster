# DP-700SH 追加根拠 — 2026-09-11 04:25 JST

## 新規に確認できた事実

### 1. Sunplus mMedia は2008年にDPF専用SoC `SPMP2800` 系列を公式発表していた

Sunplus公式の2008-01-04プレスリリースで、子会社 Sunplus mMedia がデジタルフォトフレーム（DPF）向けSoC `SPMP2800 series` をCES 2008で発表している。

公式記載上の主な機能:
- ハードウェアJPEG codec
- 5〜10インチのアナログ/デジタルLCD対応タイミングコントローラ
- RTC
- power-on controller
- PWM / LCD power controller
- USB
- NAND Flash / memory-card interface
- Wi-Fi対応構成

出典:
- Sunplus公式プレスリリース（2008-01-04）: https://w3.sunplus.com/press/press.asp?id=4B443324335524

### 2. Sunplus mMedia のPMP/MP3/DPF製品群は2009年秋にGeneralplusへ分割移管された

Sunplus公式Milestonesは、2009年にSunplus mMediaの製品群を再編し、`PMP/MP3/DPF` を Generalplus Technology Inc. へ移したことを記録している。DigiTimesも2009-10-16に、Sunplus mMediaのdigital picture frame product lineをGeneralplus等へ移管する再編を報じた。Sunplusの財務資料では、2009-11-04の株主決議によりMP3/PMP/DPF製品群（帳簿価額NT$218,442千）をGeneralplusへ分割したと記載される。

出典:
- Sunplus公式Milestones: https://www.sunplus.com/about/milestones.asp
- DigiTimes, 2009-10-16: https://www.digitimes.com/news/a20091016PD216.html
- Sunplus財務資料（2009年再編の記載を含む）: https://device.report/m/762a0f5803db9de0e6f24b5f131f31e24150097572be60747a39213eb6c321dc.pdf

### 3. 同時代のSunplus mMedia製DPF基盤にはThreadX/MIPS/SD・USB更新機構の実例がある

2018年公開・2026年更新の技術者による実機解析記事では、2009年第39週製造の `SPMF2800` 表記SoCを搭載した別メーカーのデジタルフォトフレームが解析されている。これはDP-700SHそのものではないが、同時代Sunplus系DPF基盤の具体的な実装例になる。

記事で実機から確認された内容:
- `SPMF28XX Boot Loader`
- MIPS32 4K系CPUとみられるコード
- Express Logic ThreadX (`ThreadX MIPS32_4Kx/GNU Version G4.0c.R`)
- SPI Flash 2MB / SDRAM 8MB
- SDカード・USBメモリ経由のupgrade機構
- UART 115200bpsのコマンド操作
- `Evm RC Driver`（リモコンドライバ）
- firmwareはLZO圧縮部分を含む

出典:
- Qiita「[失敗]フォトフレームHack」: https://qiita.com/yamori813/items/2919b6344e7e27704726
- Qiita「続フォトフレームHack」: https://qiita.com/yamori813/items/130a2478766c75295348

### 4. 2011年6月末、Sunplusの100%子会社Lin Shih InvestmentがSanJet株を少額保有していた

Sunplus公式の2011年上期財務諸表を表画像・本文の両方で再確認した。

- Sunplus Technologyは `Lin Shih Investment Co., Ltd.` を100%保有していた。
- Lin Shih Investmentの保有有価証券一覧には `Sanjet Technology Corp.` がある。
- SanJetは `Equity-method investee` ではなく **`Financial assets carried at cost`** と分類されている。
- 2011-06-30時点で25千株、帳簿価額NT$215千。
- 同じLin Shih InvestmentはAIPTEK International株も136千株保有していた（こちらはavailable-for-sale financial asset）。

出典:
- Sunplus Technology, 1H2011 Financial Statements: https://www.sunplus.com/ir/info/2011Q2EN.pdf

## 状況証拠としての意味

DP-700SH / DP-850SH / DP-1020SH のSoC候補として、既存のITE `IT9834` / `IT9836` に加えて **Sunplus mMedia → Generalplus系DPF SoC** も優先照合対象にする価値がある。

理由は、(1) Sunplus mMediaが2008年からDPF専用SoCとSDKを実際に提供していたこと、(2) 2009年10〜11月という `FUJIFILM DP-850SH/DP-1020SH / Customer: Sharp` 案件開始時期とほぼ同時にDPF製品線がGeneralplusへ移管されたこと、(3) 後年ではあるがSunplus側の100%子会社がSanJet株を保有していたこと、の3点。

また、別製品のSPMF2800実機でThreadX/MIPS、SD/USB upgrade、リモコンドライバが確認されているため、もし `TH34_dpf.pkg` を回収できた場合は以下の文字列・特徴を優先して探索する価値がある。

- `ThreadX`
- `Express Logic`
- `MIPS32_4Kx`
- `SPMF28XX`
- `Sunplus mMedia`
- `Generalplus`
- LZO圧縮痕跡
- `Evm RC Driver`

## 断定してはいけないこと

- DP-700SH / DP-850SH / DP-1020SHにSunplus/Generalplus SoCが搭載された証拠はまだない。
- `SPMF2800` 実機解析は別メーカーのデジタルフォトフレームであり、DPシリーズのOSがThreadXだったことを示さない。
- 2011年のSanJet株保有を2009〜2010年へ遡及して、SunplusとSanJetに当時から取引・資本関係があったと断定しない。
- SanJetはSunplusの持分法適用会社ではない。今回確認できたのは、Sunplusが100%保有する投資会社Lin Shih Investmentによる少額の原価計上株式保有である。
- Sunplus/Generalplus候補の追加は、既存のITE `IT9834` / `IT9836` 候補を否定するものではない。
