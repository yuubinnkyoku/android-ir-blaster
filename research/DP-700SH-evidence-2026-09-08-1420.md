# DP-700SH 調査追補 — AIPTEK時代のデジタルフォトフレーム開発実績

調査日: 2026-09-08 JST

## 確定事項

SanJet Technology（勝捷光電）の前身側にあたる天瀚科技 / AIPTEKは、SanJetへの代工部門分割より前からデジタルフォトフレームを実際に製品化していた。

### AIPTEK Monet（2007年）

2007-12-10のAIPTEK International GmbHプレスリリース転載記事で、8型16:9・800×480のデジタルフォトフレーム `Monet` が確認できる。

主な仕様:
- 8型 800×480
- JPEG表示
- 動画再生
- MP3 BGM
- SD / MMC / CF / MS / MS Pro
- USB
- カレンダー / 時計 / アラーム
- 付属リモコン
- 5V電源

出典:
- https://www.photoscala.de/2007/12/10/digitalbildrahmen-monet-von-aiptek/
- https://www.manua.ls/aiptek/monet/manual

### AIPTEK Monet BT（2008年）

2008-02-18のAIPTEK公式プレスリリース転載記事では、`Monet BT` がBluetooth EDR 2.0を搭載し、携帯電話/PDAから画像・音楽・動画を受信できるデジタルフォトフレームとして発表されている。表示は8型800×480で、MPEG系動画・MP3・リモコンを備える。

出典:
- https://www.photoscala.de/2008/02/18/bluetooth-bilderrahmen-monet-bt-von-aiptek/
- https://www.digitalkamera.de/Meldung/Aipteks_Monet_BT_stellt_Bilder_direkt_vom_Handy_oder_PDA_dar/4659.aspx

### AIPTEKは2008年にDPFを主要新製品としていた

天瀚科技の会社紹介資料には、2008年の主要な世界初製品の一つとして「世界第一台可拍照的數位相框」（写真撮影可能なデジタルフォトフレーム）が明記されている。

出典:
- https://114229.web66.tw/

また、2008-11-11にはAIPTEKが `Monet LE`（8型800×600、512MB、リモコン、スライドショー）を発表しており、単発ではなく複数世代のDPF製品群を持っていた。

出典:
- https://www.photoscala.de/2008/11/13/digitalbildrahmen-monet-le-von-aiptek/

## DP-700SH調査との関係 — 状況証拠

既存調査では、
- 2009年に天瀚科技の代工部門からSanJet側へ人員・製造/R&D機能が分かれたこと
- SanJetが2009年6月に `數位相框` を指定商品として商標出願したこと
- 2009年10月〜2010年2月ごろの台湾側職歴に `FUJIFILM DP-850SH / DP-1020SH`, `Customer: Sharp` が現れること
が確認されている。

今回の資料により、そのチーム系統はSharp/FUJIFILM案件の直前に初めてDPFへ参入したのではなく、**少なくとも2007年末〜2008年にはAIPTEKとして8型800×480、動画/音声、メモリカード、USB、リモコンを備えるDPFを量産・販売していた**ことが確認できる。

DP-850SHも8.5型800×480、動画/音声、複数種メモリカード、USB、リモコンを持つため、機能カテゴリには強い連続性がある。

## 推測 / 断定禁止

- AIPTEK Monet/Monet BTとDP-700SH/850SH/1020SHが同一SoC、同一OS、同一基板、同一ファームウェア系統だった証拠はない。
- 表示解像度や機能が似ること自体は当時のDPFでは珍しくなく、これだけで共通プラットフォームとは言えない。
- ただしSanJet側のDPF設計能力がSharp案件以前から存在したことは、ODM/開発チーム連続性を考える上で新しい補強材料になる。

## 次に狙うもの

AIPTEK Monet / Monet BT / Monet LEについて、FCC・認証資料、基板写真、ファームウェア更新ファイル、USB VID/PID、サービス資料を探す。SoCまたはOSが判明すれば、SanJetへ移った旧DPFプラットフォームとDP-700SH系列の比較が可能になる。
