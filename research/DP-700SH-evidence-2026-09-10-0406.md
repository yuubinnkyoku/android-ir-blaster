# DP-700SH evidence — 2026-09-10 04:06 JST

## 新規根拠: `RRMCG...` はSharp自身が使うリモコン型番体系

### 確定事項

DP-700SH純正リモコンの実機裏面で確認済みの型番は `RRMCG2009SCZZ`。

今回、Sharp公式資料およびSharpサービス資料を照合し、`RRMCG` で始まる型番がSharp自身のリモコン／サービス用リモコンの型番体系として使われていることを確認した。

1. Sharp公式 `PG-M25X` 取扱説明書の適合宣言では、機器種別を `Remote Control`、型番を **`RRMCG 1653CESA`** と明記している。
   - https://global.sharp/products/pdf/pg-m25x/m25x_k.pdf

2. Sharp公式 `PG-C30X` 取扱説明書でも、リモコン本体表示として `REMOTE CONTROL MODEL NO.: RRMCG ... CESA` を掲載している。
   - https://global.sharp/products/text/pdf/pg-c30x/manuals/usa/c30_usp.pdf

3. Sharp VL-C650S 系サービスマニュアルでは、調整用サービスリモコンを **`RRMCG0033TASA`** と明記し、FLASH MEMORY / EEPROM の調整操作に用いるSharpサービス部品として扱っている。
   - https://manualzilla.com/doc/7445906/sharp-vl-c650s-service-manual

4. Sharp PG-C45S の公式取扱説明書では、交換部品としてリモコン **`RRMCG A029WJSA`** を列挙している。
   - https://global.sharp/products/xg_c50x/pdf/c45s_i.pdf

### 状況証拠

DP-700SHの `RRMCG2009SCZZ` は、単にFUJIFILMが独自につけた市販アクセサリー名というより、**Sharpの既存部品番号体系に沿ったリモコン型番である可能性が非常に高い**。

DP-700SH本体銘板の `製造元: シャープ株式会社`、2010年3機種のSharp製液晶、Sharp名義ACアダプターなどの既知情報と合わせると、少なくとも純正リモコンについてもSharp側の部品管理／設計・調達系統に乗っていたことを補強する。

このため赤外線コード探索では、FUJIFILM固有方式だけでなく、**同時期Sharp製品の赤外線プロトコル／Sharp 13-bit系を優先候補とする現在の方針には追加の根拠が付いた**。

### 推測

- `RRMCG2009SCZZ` の赤外線符号そのものもSharpの標準的な13-bit方式を使う可能性がある。
- DP-700SH / DP-850SH / DP-1020SH の同外観リモコンが同じSharp部品番号・同じIRコードセットを共有している可能性が高い。

### 断定禁止

- `RRMCG` 接頭辞だけでは、`RRMCG2009SCZZ` がSharp 13-bit赤外線方式であることは証明できない。Sharp製リモコンでも製品世代・用途によって別方式や異なるアドレス体系を使い得る。
- `RRMCG2009SCZZ` の搬送波周波数、アドレス、コマンド値、生波形は依然未回収。
- 公式Sharp資料で **`RRMCG2009SCZZ` そのもの**をSharp交換部品として掲載した資料は今回未発見。今回確定したのは `RRMCG...` がSharp自身のリモコン型番体系であること。
