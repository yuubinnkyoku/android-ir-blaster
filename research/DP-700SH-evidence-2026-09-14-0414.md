## 新規に確認できた事項

### DP-1020SHは「音楽機能無しの下位機種」と同じリモコンを採用したという発売直後の所有者証言

2010-04-06の価格.com DP-1020SHレビューで、購入者 `google_guta` 氏が操作性について次のように記録している。

> 「まずリモコンからして音楽機能無しの下位機種と同じものです」

DP-1020SHと同じ2010年2–3月発表の3機種のうち、DP-850SHも動画・音楽再生対応であり、**動画・音楽非対応なのはDP-700SHだけ**。したがって、この「音楽機能無しの下位機種」はDP-700SHを指すと読むのが自然である。

出典:
- DP-1020SHレビュー（2010-04-06）: https://review.kakaku.com/review/K0000084347/ReviewCD=304627/
- 3機種仕様比較（DP-700SHのみ動画・音声非対応）: https://www.phileweb.com/news/d-av/201002/02/25247_3.html
- 同内容を報じるデジカメWatch: https://dc.watch.impress.co.jp/docs/news/346441.html

**確定度:** 中〜高。レビューはメーカー資料ではなく購入者証言だが、発売直後の実機所有者が具体的に比較しており、3機種の機能差から対象機種はDP-700SHにほぼ一意に絞れる。

### DP-700SH / DP-850SH / DP-1020SHの付属リモコン前面デザインは一致する

中古実機の付属品写真を比較すると、3機種とも同じ15ボタン配置のFUJIFILMリモコンが写っている。

共通配置:

- 左 / 決定 / 右
- 戻る / 下
- スライドショー / インデックス / モード切替
- 便利メニュー / 時計 / 絞り込み
- 縮小 / 拡大 / 回転

`RRMCG2009SCZZ` 背面ラベルは `REMOTE CONTROL UNIT / RRMCG2009SCZZ / 使用電池 リチウム電池 CR2025 1個 / FUJIFILM Corporation`。

**確定:** DP-700SHの純正リモコン型番が `RRMCG2009SCZZ` であることは既確認。DP-850SHおよびDP-1020SHの付属リモコンは、少なくとも外観・ボタン配置がDP-700SH用 `RRMCG2009SCZZ` と一致する。

**推測:** DP-850SH / DP-1020SHも型番 `RRMCG2009SCZZ` をそのまま共用していた可能性が高い。特にDP-1020SHは発売直後の所有者レビューが「音楽機能無しの下位機種と同じリモコン」と明記している。

**未確定:** DP-850SHまたはDP-1020SHと一緒に写ったリモコンの背面ラベル `RRMCG2009SCZZ` を一枚の写真で直接確認した例、またはFUJIFILM公式部品表・互換表。

## リバースエンジニアリング上の意味

- DP-700SH / DP-850SH / DP-1020SH間で、少なくともリモコン受信プロトコルと共通キー群が共通である可能性が非常に高くなった。
- `RRMCG2009SCZZ` のIRコードを実測できれば、DP-700SHだけでなくDP-850SH/DP-1020SHにもそのまま適用できる可能性が高い。
- DP-1020SHには音楽再生機能があるにもかかわらず、リモコン側に曲送り専用キー等を追加していない。これは3機種をまたぐ共通入力層/共通UI基盤を優先した設計と整合する。
- ただし、共通リモコンはSoC・メイン基板の同一性までは示さない。受光デコーダや上位ソフトウェアで同じキー集合を処理しているだけでも説明できる。
