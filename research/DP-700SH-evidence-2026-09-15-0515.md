# DP-700SH research evidence — 2026-09-15 05:15 JST

## 今回の新規根拠

### DP-70SH公式ファーム `TH180700.ver` に内部イメージ表が存在する

Wayback Machineに保存されたFUJIFILM公式ファーム本体 `TH180700.ver`（2016-06-23 11:31:10保存）をrawで再確認したところ、バイナリ後半に次のASCII文字列が**連続した表として**存在する。

- `BOOT`
- `NVRAM`
- `NVRAM_2`
- `ROMTAB`
- `STRTAB`
- `FIRMWARE`
- `VERSION`
- `CHECKSUM`

同じバイナリには既知の `SHARP_PF100_PLATFORM` のほか、`FW Revision: V%d.%02d`、`NEW SERIAL FLASH`、`SPI`、`MXIC`、`ATMEL`、`boot_comm`、`TaskMgr`、`task switching..`、`SliceCycles:` なども入っている。

出典（FUJIFILM公式配布物のWayback保存版）:
- original: `http://download.fujifilm.co.jp/pub/tools/dp70sh/TH180700.ver`
- archived raw: https://web.archive.org/web/20160623113110id_/http://download.fujifilm.co.jp/pub/tools/dp70sh/TH180700.ver

### 圧縮ペイロードの存在を強く示す痕跡

上記の内部イメージ表付近で、rawレスポンス中に gzip の標準ヘッダに対応する `1f 8b 08` の並びが確認できる。また同じファーム内に次の文字列がある。

- `gz_size`
- `inflated`
- `load_...` 系のデバッグ文字列

したがって、少なくとも `TH180700.ver` の更新イメージには **gzip/deflate圧縮された領域が含まれる、または更新ローダがその形式を展開する実装を持つ可能性が高い**。

## 確定事項

1. `TH180700.ver` はFUJIFILM公式配布物としてWaybackに実バイナリが保存されている。
2. バイナリ内部に `BOOT / NVRAM / NVRAM_2 / ROMTAB / STRTAB / FIRMWARE / VERSION / CHECKSUM` の文字列群がまとまって存在する。
3. `SHARP_PF100_PLATFORM`、`FW Revision: V%d.%02d`、serial flash関連の文字列が同一ファームに存在する。
4. rawデータにgzipヘッダに対応する並びがあり、同時に `gz_size` / `inflated` が存在する。

## 高確度の推測

- `BOOT` などの8項目は、更新ファイル内の領域名・イメージ名・区画名を記述するメタデータ表である可能性が高い。
- `TH180700.ver` は単純な単一実行バイナリではなく、ブート領域・NVRAM・テーブル・本体ファームなどをまとめた更新コンテナである可能性が高い。
- gzipヘッダと展開関連文字列から、コンテナの少なくとも一部を展開して静的解析できる可能性がある。

## 断定しないこと

- 現時点ではbyte-perfectなローカルコピーを用いたオフセット解析を行っていないため、各領域の開始位置・長さ・チェックサム方式は未確定。
- `ROMTAB` / `STRTAB` が一般的な意味でのROM table / string tableなのか、Sharp側独自名称なのかは未確定。
- gzipを使うことだけからSoC・CPU・RTOSを特定することはできない。
- DP-700SH/850SH/1020SHの `.pkg` が同一コンテナ形式を継承している証拠はまだない。ただし2010年ファームを回収できた際の最優先照合項目になる。
