# DP-700SH 追加根拠 — ITE IT9834 / IT9836 候補

調査日時: 2026-09-09 21:58 JST

## 新しく確認できた事実

2009-12-10の台湾 DigiTimes 記事で、聯陽半導體（ITE Tech）がデジタルフォトフレーム専用の3Dグラフィックス加速SoCとして `IT9834` / `IT9836` を正式発表していたことを確認した。

記事に明記されている内容:

- `IT9834` / `IT9836` はデジタルフォトフレーム向け専用SoCとして発表された。
- 既に「國外大廠指定使用」（海外大手メーカーから指定採用）を獲得したとされる。
- `IT9834` は JPEG / M-JPEG codec、MPEG1/4 decoder、Audio engine を統合。
- SD / MMC / xD / MS / MS PRO / CF のカード読取り機能を統合。
- NAND I/F は 8K page / 24-bit ECC 対応。
- ITEは複数のパートナー・顧客と、この系列を使った新しい完成品を共同開発中で、2010年第1四半期に順次発表するとしていた。
- 記事は、この製品が旧SMedia（繪展科技）のグラフィックス技術を受け継いだとも説明している。

別の2010年前後の業界記事でも、ITEが `IT9834` / `IT9836` の海外大手向け受注を得て、2010年第1四半期に関連完成品を順次投入する見込みだったと報じられている。

## DP-700SH系との接続 — 状況証拠

これはDP-700SH / DP-850SH / DP-1020SHへの搭載を直接示す資料ではない。ただし、既存の調査結果と時期・機能がかなり強く重なる。

- 台湾側の公開職歴では、FUJIFILM `DP-850SH/DP-1020SH` / `Customer: Sharp` の開発期間が 2009-10〜2010-02。
- ITEの発表は2009-12-10で、まさにその開発期間中。
- ITEは新しい顧客製品が2010年Q1に順次出るとしていた。
- FUJIFILMのDP-700SH / DP-850SH / DP-1020SHは2010年Q1に市場投入された。
- `IT9834` の統合カード媒体 SD / MMC / xD / MS / MS PRO / CF は、当時の上位デジタルフォトフレームで必要になる媒体構成と非常に近い。
- JPEG/M-JPEG、MPEG1/4、音声処理を単一SoCにまとめる構成も、DP-850SH / DP-1020SHの動画・音声対応機能と整合する。

したがって `IT9834` / `IT9836` は、今後DPシリーズの基板写真やファームウェアを入手した際に優先照合すべき **具体的SoC候補** とする価値がある。

## 推測 — 断定しないこと

- DP-700SH / DP-850SH / DP-1020SHに `IT9834` または `IT9836` が搭載されていたとは未確認。
- DigiTimesの「海外大手メーカー」がSharpまたはFUJIFILMだったとは確認できない。
- 台湾側担当者 Dusty Shyr / 石璧維がITEまたは旧SMedia所属だったという証拠は今回得られていない。
- `IT9834` と `IT9836` のどちらが7/8/10型のどの機種に適するかも不明。
- 現在公開されている2021年以降の `IT983x` 資料にはRISC-V等の現代的仕様が記載されるが、これを2009年発表品の内部アーキテクチャへそのまま遡及してはならない。型番系列が長期間継続・再設計された可能性を考慮する。

## 実機での次の確認ポイント

基板を開けられる場合は、メインSoC刻印として `ITE` / `IT9834` / `IT9836` / `SMedia` 系表記を優先して確認する。`TH34_dpf.pkg` 等が回収できた場合は、文字列・ヘッダ・ドライバ名から `ITE`、`IT983`、`SMedia`、カードコントローラ関連識別子を検索する。
