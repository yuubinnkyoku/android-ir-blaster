# DP-700SH 調査追記 — 2026-09-23 14:14 JST

## 新規根拠: Sharp HN-PP150にも「バージョン画面 + 隠しキー列」で更新メニューを出す保守UIが存在

### 確定事項

Sharp公式の `HN-PP150 ファームウェア書換え手順` PDFには、AQUOSフォトプレーヤー HN-PP150 のファームウェア更新メニューを表示する具体的な隠し操作が記載されている。

1. スタートメニューから「各種設定と確認」を開く。
2. 「バージョンの確認」へ移動する。
3. リモコンで **赤 → 黄 → 青 → 緑** の順に押す。
4. 更新メニューが表示される。
5. SDカードのルートに **`TH150400.ver`** を置き、スロット1へ挿入して更新する。

公式PDFは更新前バージョンを `1.02.00.04～1.03.01.04`、更新後を `1.04.00.04` としている。

出典:
- Sharp公式 HN-PP150 ファームウェア書換え手順 PDF: https://jp.sharp/support/photoplayer/doc/how_to_update.pdf
- Sharp公式 HN-PP150 ファームウェア更新ページ: https://www.sharp.co.jp/support/photoplayer/fw_update.html
- Sharp公式ファームウェア配布ページ: https://jp.sharp/support/photoplayer/fw_agree.html

### DP-70SHとの比較（既知事項との接続）

FUJIFILM DP-70SHにも、バージョン表示画面でリモコンの **拡大 → 縮小 → 時計 → 回転** を順に押してファームウェア書換え画面へ入る手順が公式更新資料に存在する。DP-70SHの公式更新ファイルは `TH180700.ver`。

したがって、2008–2011年頃のSharp系写真機器では少なくとも2系列で、

- 設定画面内のバージョン表示を起点とする
- 通常UIから見えないキー列で更新メニューを出す
- SDカードのルートから `TH*.ver` を読み込む

という保守UIの設計パターンが確認できた。

### 状況証拠 / 推測

DP-70SHの回収済み公式ファーム `TH180700.ver` 内には `SHARP_PF100_PLATFORM` が存在する。HN-PP150もSharp製で、公式ファーム名が `TH150400.ver`、かつ同種の隠し更新UIを持つ。この組合せは、DP-70SHとAQUOSフォトプレーヤーがSharp内の近縁なファームウェア/保守設計文化に属した可能性を補強する。

さらに2010年DP-700SH/850SH/1020SHも `TH34_dpf.pkg` / `TH35_dpf.pkg` / `TH36_dpf.pkg` をSDカード経由で更新するため、同じ系譜が継承された可能性はある。

### 断定してはいけない点

- HN-PP150とDP-70SH/DP-700SHが同一SoC・同一基板・同一OSだった証拠ではない。
- `TH` 接頭辞だけで同一プラットフォームとは断定できない。
- DP-700SHで `赤→黄→青→緑` が有効という証拠はない。DP-700SHのリモコンには同じ色キーがないため、そのまま適用できる可能性は低い。
- DP-700SHが `SHARP_PF100_PLATFORM` を継承したかは `TH34_dpf.pkg` または実機フラッシュ回収まで未確定。

## 逆解析上の意味

`TH34_dpf.pkg` / 実機フラッシュを回収した場合、DP-70SH `TH180700.ver` と比較して、`SHARP_PF100_PLATFORM`、更新画面関連文字列、バージョン表現、ROMTAB/STRTAB、ファイル検証処理を優先的に照合する価値がある。特に更新メニューの実装・パッケージ検証コードが共通なら、SoCそのものが異なっていてもSharp側ソフトウェア系譜の直接証拠になり得る。
