# DP-700SH evidence — 2026-09-09 10:45 JST

## 2011年後継世代ではDP-701SH / DP-801SHが共通ファームウェアを使用

### 確定事項

2011-07-29、富士フイルムはデジタルフォトフレーム `DP-801SH` / `DP-701SH` のファームウェア Ver.1.04.07 を公開した。当時のデジカメ Watch記事は、**「ファームウェアは両機種で共通」** と明記している。

更新内容:
- 内蔵メモリー写真のスライドショーがまれに停止する症状の修正
- 赤外線通信の対応機種追加
- より大容量のメモリーカードへの対応
- 動画再生の改善

出典:
- https://dc.watch.impress.co.jp/docs/news/464018.html
- 旧公式ダウンロードページ: http://fujifilm.jp/support/digitalphotoframe/download/dp701sh_dp801sh/download001.html

### 2010年世代との比較

2010年の `DP-700SH` / `DP-850SH` / `DP-1020SH` も同日に共通のIrSimple/IrSS/IrDA不具合修正を受けたが、実ファイルはそれぞれ `TH34_dpf.pkg` / `TH35_dpf.pkg` / `TH36_dpf.pkg` と機種別だった。

したがって、富士フイルムのDPシリーズでは少なくとも次の違いが確認できる。

- 2010年世代: 修正内容は共通だが更新パッケージは機種別
- 2011年世代: DP-701SH / DP-801SHでファームウェア自体を共通化

### 推測・含意

これは2010年の3機種が同じソフトウェア系統を共有していた可能性を否定しない。しかし、**2010年3機種が完全に同一バイナリだったという見方には反する追加材料**になる。2011年後継世代ではメーカー側が明示的に「両機種で共通」としたため、2010年世代の `TH34/35/36` 分離は、少なくとも機種別ビルド・機種別パッケージング・ハードウェア差分のいずれかを反映していた可能性がより高い。

### 断定禁止

- 2010年3機種のSoCが異なるとは断定できない。
- 2010年3機種のOSが異なるとは断定できない。
- `TH34/35/36` の差が実行コード差分なのか、設定・パネル初期化・容量・機種識別などの差分だけなのかは、実バイナリ未回収のため不明。
- 2011年DP-701SH/DP-801SHが2010年世代と同じSoC/OSを継承した証拠はない。
