# DP-700SH 追加証拠 — ITE IT9834/IT9836 の世代識別

調査日時: 2026-09-11 JST

## 確定事項

2009-12-10 の DigiTimes 記事は、ITE Tech（聯陽半導體）がデジタルフォトフレーム向けに `IT9834` / `IT9836` を正式発表したと記録している。

当時の記事に書かれている `IT9834` の機能は、JPEG/M-JPEG codec、MPEG1/4 decoder、Audio engine、SD/MMC/xD/MS/MS PRO/CFカード読取、NAND I/F（8K page / 24-bit ECC）など。`IT9836` はこれに加えて最大1440x900・24bit LCD I/F、3D plus、Flash-like環境を持つとされる。ITEはこの系列を使った顧客製品が2010年第1四半期に順次発表されるとしている。

出典:
- DigiTimes, 2009-12-10: https://www.digitimes.com.tw/tech/dt/n/shwnws.asp?id=0000160746_OYN8H4MX31GZ7H7JMQR4S

一方、ITE自身が2021年に公開したSoC資料では、`IT983x series` の `IT9834` / `IT9837` が2018〜2023年の製品ロードマップ上に置かれ、こちらは **Dual 500MHz RISC-V CPU / 64-pin QFN / CAN / MIPI/RGB/CPU/SPI / Audio DAC/DMIC** と説明されている。

出典:
- ITE Tech, `Introduction to ITE SoC IT986x Series` (2021): https://soc.ite.com.tw/upload/2021_09_232/ITE%2ASoC%2AIT986x%2ASeries%2AIntroduction_EN.pdf
- ITE current IT983x product page: https://www.ite.com.tw/en/product/cate8/IT983X

したがって、**2009年の記事に出る `IT9834` と、2021年以降のITE公式資料に出る `IT9834` は同じ型番文字列でも仕様世代が一致しない**。ITEが型番を再利用した、あるいは後年の製品系列で同じ番号を再採番したと考えない限り両仕様は両立しない。

## DP-700SH調査への意味

### 確定

- 2009年版 `IT9834/IT9836` は、DP-700SH / DP-850SH / DP-1020SHと同時期の実在するDPF向けSoC候補である。
- 2021年以降の `IT9834` / IT983x資料にあるRISC-V、FreeRTOS、64/76-pin QFN、CAN等の仕様を、2009年版チップへそのまま適用してはいけない。

### 推測

- DPシリーズの基板に `IT9834` または `IT9836` の刻印が見つかった場合、まず2009年版DPF SoCとして扱い、現行IT983xデータシートとのピン配置・CPU・OS推定を混同しない方が安全。
- 2009年版 `IT9834/IT9836` は、カード対応や画像/動画/音声機能、発売時期の一致から依然として候補価値があるが、搭載証拠はまだない。

### 断定禁止

- DP-700SH / DP-850SH / DP-1020SH がITE `IT9834` / `IT9836` を搭載しているとは未確認。
- 2021年以降のIT983xがFreeRTOSを使うことから、2010年DPシリーズのOSをFreeRTOSと推定してはならない。
- 2009年版と2021年版が内部的に同一設計を継承しているとも言えない。
