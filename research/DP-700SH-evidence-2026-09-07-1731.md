### 2010世代との比較

既知の2010世代は以下。

- DP-700SH → `TH34_dpf.pkg` (2.1MB)
- DP-850SH → `TH35_dpf.pkg` (2.2MB)
- DP-1020SH → `TH36_dpf.pkg` (2.2MB)

2011世代では:

- DP-701SH / DP-801SH → **`TH50_dpf.pkg` (2.95MB)**

したがって、2009年DP-70SHの `TH180700.ver` とは異なり、**2010年から2011年のSH系フォトフレームでは `.pkg` + `THxx` 命名が継続していた**ことが一次資料で確認できた。

## 状況証拠 / 解釈

- `TH34` / `TH35` / `TH36` → `TH50` という番号の進行は、FUJIFILMのSH系フォトフレーム向けファームウェア生成・配布系統が2010→2011で連続していた可能性を補強する。
- 2010世代は3機種別パッケージだったのに対し、2011世代はDP-701SH / DP-801SHで同一 `TH50_dpf.pkg` を共有する。2011世代では少なくともソフトウェア側の機種共通化が一段進んでいたと考えられる。
- DP-701SHはDP-700SHと7型800×480、IrSimple/IrSS、miniUSB-B、専用リモコン等が近く、`TH50_dpf.pkg` は失われた `TH34_dpf.pkg` の形式・SoC/OSを逆引きする比較対象として重要。

## 断定しない事項

- `TH50_dpf.pkg` と `TH34/35/36_dpf.pkg` が同一コンテナ形式・同一SoC向けであることは未確認。
- `THxx` の数字が基板番号、SoC番号、製品世代番号など何を表すかは不明。
- DP-701SH / DP-801SHがDP-700SH / DP-850SH / DP-1020SHと同一ODM、同一OS、同一CPUを使う証拠はまだない。

## バイナリ回収状況

`TH50_dpf.pkg` の公式HTTP/HTTPS直リンクをWayback CDXで完全一致検索したが、現時点では保存スナップショットを確認できなかった。したがって実バイナリ本体は未回収。

次の狙いは、`TH50_dpf.pkg` のミラー・キャッシュ・利用者保存物を回収し、ヘッダ、圧縮形式、文字列、命令セットを解析して `TH34/35/36` との共通性を推定すること。
