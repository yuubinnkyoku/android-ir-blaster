# DP-700SH research evidence — 2026-09-08 16:29 JST

## New evidence: AIPTEK's 2007 digital-photo-frame patent explicitly includes a wireless receiver, remote controller, and sensing module

### Confirmed facts

AIPTEK International filed a patent family for a **digital photo frame with photographing function** in 2007. The Chinese utility-model publication is **CN201119657Y**; the corresponding US publication is **US20090059052A1 / US7986368B2**.

Inventors listed in the patent family:
- 林烈诚 / Lien-Chen Lin
- 郑平溥 / Ping-Fu Cheng
- 张正伦 / Chen-Loon Chang

The disclosed system architecture is more relevant to DP-700SH reverse engineering than the previously found replaceable-frame patent because it explicitly describes internal electronic functional blocks. In the US-family text, the digital frame includes:
- display module
- memory module
- control module
- input module
- power-supply module
- **sense module**

The patent further states that the **input module includes a wireless receiving module and a remote controller** (`wireless receiving module 161` / `remote controller 162`).

Sources:
- Google Patents, CN201119657Y: https://patents.google.com/patent/CN201119657Y/en
- Patsnap/Eureka copy of US20090059052A1, especially the embodiment around [0033]: https://eureka.patsnap.com/patent-US20090059052A1
- Justia patent index for US7986368: https://patents.justia.com/patent/7986368

### Why this matters

This is direct evidence that the **AIPTEK/天瀚 digital-photo-frame engineering organization already had a DPF architecture using remote-control wireless reception and a separate sensing block by 2007**, before the 2009 split that led to SanJet and before the 2009-2010 Sharp/FUJIFILM DP-850SH/DP-1020SH development project recorded in the Taiwan-side engineer's work history.

The observation is compatible with several features later seen in the 2010 FUJIFILM series:
- dedicated remote-controller receiver
- separate image-transfer infrared function
- ambient-light sensing / automatic power behavior
- display + memory + controller architecture

### Inference (not confirmed)

This strengthens the hypothesis that at least some **DPF subsystem know-how** — including remote-control input and sensor integration — existed in the AIPTEK-side engineering base that later fed into SanJet's ODM organization.

However, the patent does **not** identify the SoC, RTOS/OS, IR carrier frequency, IR protocol, remote-control command values, PCB layout, or any FUJIFILM/Sharp model. It also does not show that this exact architecture or source code was reused in DP-700SH/DP-850SH/DP-1020SH.

### Important negative result

The patent's current assignee remains AIPTEK in the sources checked; unlike CN201153780Y, no SanJet assignment was found for this specific patent in this run. Therefore it is evidence of **pre-SanJet AIPTEK DPF capability**, not direct proof of IP transfer for this particular remote/sensor design.
