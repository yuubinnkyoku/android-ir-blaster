# DP-700SH 調査追補 — 2026-09-11 20:04 JST

## 後継 DP-701SH / DP-801SH の公式ファーム配布実体情報

### 確定事項

Wayback Machine に保存された FUJIFILM 公式の `DP-701SH／DP-801SH ファームウエアの更新` ダウンロードページを確認した。

保存ページ:
- https://web.archive.org/web/20140722194942/http://fujifilm.jp/support/digitalphotoframe/download/dp701sh_dp801sh/download002.html

ページには、DP-701SH / DP-801SH **両機種用として1つのファームウェアパッケージ**が掲載されている。

- ファイル名: `TH50_dpf.pkg`
- バージョン: `Ver.1.04.07`
- 表示容量: `2.95MB`
- 公式直リンク: `http://download.fujifilm.co.jp/pub/tools/jtnjcxxwbhehyq/TH50_dpf.pkg`

2010年世代で既に回収済みの以下の配布情報と合わせると、FUJIFILMのデジタルフォトフレーム向け更新パッケージで `THxx_dpf.pkg` という命名が後継世代でも継続していたことが確認できる。

- DP-700SH: `TH34_dpf.pkg` 2.1MB
- DP-850SH: `TH35_dpf.pkg` 2.2MB
- DP-1020SH: `TH36_dpf.pkg` 2.2MB
- DP-701SH / DP-801SH: `TH50_dpf.pkg` 2.95MB

また、DP-700SH / 850SH / 1020SHでは機種別の `TH34` / `TH35` / `TH36` が配布されていたのに対し、後継DP-701SH / DP-801SHでは公式ページ上で**同一の `TH50_dpf.pkg` を2機種共通として配布**している。

### 状況証拠・解釈

- `THxx_dpf.pkg` は少なくとも2010年世代だけの一時的な名前ではなく、2011年後継世代でも使われたファームウェア・パッケージ命名規則だった可能性が高い。
- DP-701SH / DP-801SHが同一配布バイナリを使うことは、後継2機種のソフトウェア基盤がかなり共通化されていたことを示す。ただしメイン基板やSoCが同一であることまでは証明しない。
- 後継機のダウンロードURLはモデル名ディレクトリではなく `jtnjcxxwbhehyq` というランダム風のパスを使用している。したがって、FUJIFILM旧配布ファイルの探索では `dp700sh/` 等のモデル名パスだけを対象にすると、別世代や後期配布を見落とす可能性がある。
- `TH50` の存在だけから、`TH34` / `TH35` / `TH36` とファイル内部形式、SoC、OSが同一とは判断できない。
