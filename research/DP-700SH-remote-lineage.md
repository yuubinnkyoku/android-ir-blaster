# FUJIFILM デジタルフォトフレーム リモコン系譜調査

最終更新: 2026-08-20 JST

## 目的

DP-700SH純正リモコンの正式型番とIRコードを特定するため、FUJIFILMデジタルフォトフレーム用として中古市場に残るリモコン型番を系譜化する。

## 確認できた型番

### RRMCG2007SCZZ

FUJIFILMデジタルフォトフレーム用リモコンとしてYahoo!オークション等の中古索引に複数件残る。

同じ検索面にはDP-S7V用リモコンの出品も存在するが、`RRMCG2007SCZZ = DP-S7V用` と直接書いた記録はまだ未確認。検索面の隣接だけで対応を断定しない。

### RRMCG2009SCZZ

FUJIFILM DIGITAL PHOTO FRAME用リモコンとして複数の中古記録がある。

確認例:
- Yahoo!フリマ `g1043790009`: 型番RRMCG2009SCZZ、全ボタン赤外線動作確認済み
- 楽天中古索引 `C2J710`, `C2J726`
- メルカリにも同型番単品が複数存在

DP-700SH / DP-850SH / DP-1020SHとの直接対応はまだ文字情報では確認できていない。

### RRMCG2010SCZZ

FUJIFILMフォトフレーム用リモコンとして中古市場に存在。

確認例:
- メルカリ `m65503506825`: 「富士フィルム フォトフレームリモコンRRMCG2010SCZZ」
- ラクマ/フリル中古索引に同型番
- Yahoo!オークション過去記録にも同型番

DP-701SH / DP-801SHなどの2011世代との直接対応はまだ確認できていない。

## 重要な注意

`2007 / 2009 / 2010` の数字が製造年や採用年を直接意味する証拠はない。SHARP系の内部部品番号/設計番号である可能性もあるため、年号として扱わない。

また `RRMCG....SCZZ` がSHARP補修部品番号体系に由来する可能性は見た目上は高いが、公式部品資料で裏取りできていないため未確定。

## 2010年SHシリーズのリモコン共有仮説

DP-1020SHの実機レビューには「リモコンからして音楽機能無しの下位機種と同じもの」とある。2010年同時発表の下位機種DP-700SHは音楽/動画機能を持たないため、DP-1020SHとDP-700SHは同一または実質同一のリモコンを共有した可能性が高い。

RBB TODAYの2010年発表記事もDP-1020SH / DP-850SH / DP-700SHそれぞれをリモコン付きで掲載している。画像を回収して形状/ボタン配置を比較できれば強い証拠になる。

## 現在の候補マッピング

| リモコン型番 | 対応候補 | 確定度 |
|---|---|---|
| RRMCG2007SCZZ | DP-S7V / DP-7V系の可能性 | 低〜中 |
| RRMCG2009SCZZ | DP-70SHまたはDP-700SH/850SH/1020SH系の有力候補 | 中 |
| RRMCG2010SCZZ | DP-701SH/801SH系の可能性 | 低〜中 |

これは型番の存在時期・中古市場の文脈から置いた作業仮説であり、直接対応表ではない。

## 次に確認するもの

1. DP-700SHリモコン単品出品の裏面写真から型番を読む。
2. RRMCG2007/2009/2010の前面ボタン配置を取扱説明書画像と照合する。
3. 各型番を採用する他機種を中古部品DB/補修部品索引から逆引きする。
4. 型番をLIRC / Flipper-IRDB / RemoteCentral / JP1 / Global Caché等で検索する。
5. 1型番でも対応機種が確定したら、近縁機種IRコードからアドレス帯を絞る。
