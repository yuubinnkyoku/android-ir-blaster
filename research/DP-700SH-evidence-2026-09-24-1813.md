# DP-700SH investigation evidence — 2026-09-24 18:13 JST

## New evidence: Sharp HN-PP100/HN-PP150 used eCROS / PrKERNELv4

### Confirmed

A primary-source eSOL press release dated 2009-05-12 states that Sharp-developed AQUOS Photo Player HN-PP100 and HN-PP150 adopted eSOL's `eCROS` software platform.

The release gives the stack in unusually concrete detail:

- μITRON 4.0-compliant real-time OS: `PrKERNELv4`
- development suite: `eBinder`
- filesystem
- SD Memory Card and Memory Stick media drivers
- USB host stack

It also states that the Sharp HN-PP100/HN-PP150 support SD/SDHC, Memory Stick, CompactFlash, USB camera input and high-speed infrared `IrSS`.

Source:
- eSOL, 2009-05-12, 「シャープのAQUOSフォトプレーヤーにイーソルのソフトウェアプラットフォーム『eCROS』が採用」
  https://www.esol.co.jp/archive/news/emb_press090512.html

Sharp's official HN-PP100 page independently confirms its interfaces: SD/Memory Stick, CompactFlash, USB-A, IrSS and a dedicated infrared remote.

Source:
- Sharp HN-PP100 official product page
  https://jp.sharp/products/av/photoplayer/prod01/hnpp100w/index.html

### Relevance to DP-700SH / DP-70SH

This is stronger OS-family evidence than the previously found Sharp JD-7C1CL/CW example because HN-PP100/HN-PP150 are themselves Sharp photo-player products, not a telephone with photo-frame functionality. Their storage/removable-media/USB/IrSS feature set also overlaps substantially with the FUJIFILM/Sharp photo-frame line.

Separately, the recovered official DP-70SH firmware `TH180700.ver` contains the platform string `SHARP_PF100_PLATFORM`. The naming resemblance between `PF100` and Sharp's HN-PP100 is noteworthy but **must not be treated as an identification**: no source currently proves that `PF100` denotes HN-PP100, that the two share a board/SoC, or that DP-70SH/DP-700SH run eCROS.

### Working hypothesis / next binary checks

Because Sharp demonstrably used eCROS/PrKERNELv4 in a closely related photo product at the same time, DP-70SH/DP-700SH firmware should be checked for:

- `PrKERNEL`, `PrKERNELv4`
- `eCROS`, `eBinder`, `eSOL`
- μITRON service-call names such as `act_tsk`, `wai_sem`, `sig_sem`, `snd_mbx`, `rcv_mbx`
- eSOL filesystem / USB middleware identification strings

A positive vendor/product string would materially strengthen the OS attribution; generic μITRON API-like strings alone would not prove eCROS.

## Explicitly not established

- DP-70SH or DP-700SH uses eCROS/PrKERNELv4.
- `SHARP_PF100_PLATFORM` means HN-PP100.
- HN-PP100 and DP-70SH/DP-700SH share the same SoC or PCB.
- This evidence identifies the Taiwanese ODM for DP-700SH/850SH/1020SH.
