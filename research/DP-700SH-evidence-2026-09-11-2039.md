# DP-700SH 追補根拠 — 2026-09-11 20:39 JST

## 今回の新情報

### 確定事項: 前世代 DP-70SH にはリモコンによる隠しファーム更新遷移がある

2009-04-01のデジカメ Watch記事では、FUJIFILM DP-70SH の Ver.1.04.00 更新手順として、フォーマット済みSDカードにファームウェアを保存し、設定メニューの「本体情報の表示」内で「バージョン表示」を表示した状態から、リモコンの

`拡大 → 縮小 → 時計 → 回転`

を順に押すと「ファームウェア書き換え画面」に切り替わる、と明記されている。

出典:
- https://dc.watch.impress.co.jp/cda/accessories/2009/04/01/10602.html

同記事で確認できる DP-70SH の要素:
- 7型 800×480
- SHARP ASV液晶
- IrSimple
- JPEG表示
- 2009年3月発売
- 公開ファーム Ver.1.04.00

### 確定事項: DP-700SH 純正リモコンには上記4キーがすべて存在する

`RRMCG2009SCZZ` の実物写真では、前面に `拡大`、`縮小`、`時計`、`回転` の各キーが確認できる。したがって DP-70SH の更新遷移に必要な4操作は、DP-700SH世代の純正リモコンでも物理的に実行可能。

出典:
- https://auctions.yahoo.co.jp/jp/auction/g1043790009
- https://auctions.yahoo.co.jp/jp/auction/u1044487922

### 既知事項との接続

DP-700SH 実機でも設定メニューに「本体情報の表示」が存在し、Ver.1.03.00 を表示できることは既知。公式更新版は Ver.1.04.00。

DP-70SH と DP-700SH は、少なくとも以下を共有する。
- FUJIFILM のデジタルフォトフレーム系列
- SHARP製液晶（7型・800×480・ASV）
- IrSimple系画像転送
- リモコン操作
- 「本体情報の表示」→バージョン表示という設定UI

## 推測 / 実機検証候補

### 有力だが未確定

DP-700SH / DP-850SH / DP-1020SH でも、DP-70SHと同じ `拡大 → 縮小 → 時計 → 回転` をバージョン表示中に送ることで、ファームウェア書き換え画面またはサービス系画面へ入れる可能性がある。

これはUIとキー集合の継承から導く仮説であり、現時点では DP-700SH で同じ隠しシーケンスが有効という直接証拠はない。

### 重要な注意

- DP-70SH と DP-700SH が同一SoC / 同一OS / 同一ブートローダであるとは断定できない。
- 両機の公開ファームがともに Ver.1.04.00 であることも、同一コードベースの証明にはならない。
- DP-700SHの公式更新手順PDFそのものから同じ4キーシーケンスを直接確認できていない。

## リバースエンジニアリング上の意味

`RRMCG2009SCZZ` のIRコードを1つでも回収でき、4キーのコード集合まで特定できれば、DP-700SH実機でこの隠し更新遷移を安全に試す価値がある。成功すれば、SDカード上の `TH34_dpf.pkg` を読む更新ローダの存在・UI・検証処理へ直接アクセスできる可能性がある。

一方、今回も `TH34_dpf.pkg` / `TH35_dpf.pkg` / `TH36_dpf.pkg` の実バイナリ、SoC刻印付き基板写真、OS/RTOS、公開済みの生IRコードは見つからなかった。
