# DP-700SH 調査追補 — 2026-09-05 22:31 JST

## 今回の新規根拠

### 確定事項: 2011年後継 DP-701SH / DP-801SH は「両機種共通」のファームウェアだった

2011-07-29のデジカメ Watch記事は、FUJIFILM DP-701SH / DP-801SH向け Ver.1.04.07 について、**「ファームウェアは両機種で共通」**と明記している。

出典:
- https://dc.watch.impress.co.jp/docs/news/464018.html
- 旧公式更新ページ: http://fujifilm.jp/support/digitalphotoframe/download/dp701sh_dp801sh/download001.html
- Wayback保存版: https://web.archive.org/web/20111104091802id_/http://fujifilm.jp/support/digitalphotoframe/download/dp701sh_dp801sh/download001.html

Waybackで2011-11-04保存の公式更新ページも確認した。両機種の対象バージョンは共通して `1.04.07`。更新内容には、内蔵メモリのスライドショー停止修正、赤外線通信対応機種追加、大容量メモリカード対応、動画再生処理改善が含まれる。

### 既知の2010年機との対比

2010年の DP-700SH / DP-850SH / DP-1020SH は同一のIrSimple / IrSS / IrDAハング修正を同日に受けたが、配布物は機種別に分かれている。

- DP-700SH: `TH34_dpf.pkg` (2.1MB)
- DP-850SH: `TH35_dpf.pkg` (2.2MB)
- DP-1020SH: `TH36_dpf.pkg` (2.2MB)

出典:
- https://web.archive.org/web/20120121024416id_/http://fujifilm.jp/support/digitalphotoframe/download/dp1020sh_dp850sh_dp700sh/download002.html
- https://web.archive.org/web/20100505171035id_/http://fujifilm.jp/support/digitalphotoframe/download/dp1020sh_dp850sh_dp700sh/download001.html

## 解釈

### 確定

FUJIFILMは少なくとも翌2011年世代では、画面サイズの異なるDP-701SH / DP-801SHに対して「両機種共通」のファームウェアを配布する運用を実際に行っていた。

### 状況証拠

したがって、2010年のDP-700SH / DP-850SH / DP-1020SHが同一内容の修正にもかかわらず `TH34` / `TH35` / `TH36` の別パッケージを持つことは、単なるWeb配布上の慣習だけでは説明しにくい。

少なくとも2010年3機種では、機種ごとのビルド差、設定差、搭載デバイス差、またはハードウェア差を吸収するために別イメージが必要だった可能性が、2011年後継機との比較によって少し強まる。

### 未確定

- 2010年3機種のSoCが同一か別か。
- `TH34` / `TH35` / `TH36` の差分が、液晶タイミング・内蔵メモリ容量・動画/音声機能・周辺デバイス・ブートローダ等のどこに由来するか。
- 2011年DP-701SH/DP-801SHの実ファームウェアファイル名。Waybackには `download001.html` は残るが、今回 `download002.html` の保存は確認できなかった。
- 2011年世代と2010年世代が同一SoC/OS系列かどうか。

## 今回再確認した未回収項目

- `TH34_dpf.pkg` / `TH35_dpf.pkg` / `TH36_dpf.pkg` 本体: Waybackに実バイナリ保存なし。
- `RRMCG2009SCZZ` の搬送波・プロトコル・各キーコード: 公開コードデータなし。
- DP-700SH / 850SH / 1020SHの判読可能な基板・SoC写真: 新規直接証拠なし。
