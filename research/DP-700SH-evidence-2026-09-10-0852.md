# DP-700SH 調査追補 — 2026-09-10 08:52 JST

## 新規根拠: 先代 DP-70SH にはリモコン操作で呼び出す隠しファームウェア書き換え画面がある

2009-04-01のデジカメ Watch記事で、FUJIFILM初代デジタルフォトフレーム `DP-70SH` の公式ファームウェア Ver.1.04.00 の更新手順が具体的に記録されている。

通常の設定メニューから直接更新するのではなく、

1. フォーマット済みSDカードへファームウェアを保存
2. `本体情報の表示` → `バージョン表示` を表示
3. リモコンで `拡大` → `縮小` → `時計` → `回転` の順に押す
4. ファームウェア書き換え画面へ遷移

という手順だった。

出典:
- デジカメ Watch, 2009-04-01, 「富士フイルム、7型デジタルフォトフレームのファームウェアを公開」
  - https://dc.watch.impress.co.jp/cda/accessories/2009/04/01/10602.html
- 同機のレビュー（リモコン・背面キー・メニュー構成の実機写真あり）
  - https://dc.watch.impress.co.jp/cda/item/2009/05/08/10786.html

## 確定事項

- `DP-70SH` では、通常UI上の `本体情報の表示` / `バージョン表示` を起点に、リモコンの特定4キー列でファームウェア書き換え画面へ入る仕組みが実在した。
- キー列は `拡大` → `縮小` → `時計` → `回転`。
- DP-70SHにも `拡大` / `縮小` / `時計` / `回転` を含む専用リモコンが存在する。
- DP-70SHは2009年のFUJIFILM初代デジタルフォトフレームで、Sharp製ASV液晶、IrSimple、SD/SDHC・CF・xD・MS系対応、USB接続など、後継DP-700SH系列と機能上の連続性を持つ。

## DP-700SH解析への意味

DP-700SHの純正リモコン `RRMCG2009SCZZ` にも `拡大` / `縮小` / `時計` / `回転` が存在することは既に実物写真から確認済みである。またDP-700SHにも `本体情報の表示` / `バージョン表示` が存在し、手元実機で Ver.1.03.00 を確認済み。

したがって、DP-700SHでも同じ、または近縁のキー列で保守用ファームウェア更新画面へ入る設計が継承された可能性がある。これはIRコード探索にも意味があり、4キーのコードが特定できれば、単なる通常操作だけでなく更新入口の再現試験が可能になる。

## 推測

- `DP-70SH` から `DP-700SH/850SH/1020SH` へ、ファーム更新用の隠しキーシーケンスという設計思想が継承された可能性がある。
- 2010年世代でも `バージョン表示` 画面を起点に `拡大→縮小→時計→回転`、または近い組み合わせで書き換え画面へ入れる可能性がある。
- この入口がブートローダ側ではなく通常アプリケーション側で判定される場合、IR受信処理・キーコード表・更新処理が同一ファーム内に共存している可能性があり、`TH34_dpf.pkg` 回収後の文字列/テーブル探索対象になる。

## 断定禁止

- DP-70SHとDP-700SHで同じキーシーケンスが使えることは未確認。
- DP-70SHとDP-700SHが同じSoC、OS、ブートローダ、基板を使う証拠ではない。
- `RRMCG2009SCZZ` の赤外線プロトコルや各キーコードは、この資料からは分からない。
- 書き換え画面へ入った後の処理仕様、署名・暗号化・パッケージ検証方式も未確認。

## 実機で安全に確認する場合の優先度

`RRMCG2009SCZZ` の4キーコードを特定できた後、まずファームウェアSDカードを挿さずに `本体情報の表示` / `バージョン表示` 画面で `拡大→縮小→時計→回転` を試し、画面遷移の有無のみ確認する。書き換え実行は別途ファーム本体と復旧方法を確保してから扱う。
