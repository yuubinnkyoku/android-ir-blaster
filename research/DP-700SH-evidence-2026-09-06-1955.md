# DP-700SH 追加証拠 — 2026-09-06 19:55 JST

## 要点

DP-700SH / DP-850SH / DP-1020SH の3機種について、実物の純正付属リモコンを写した複数の公開写真を比較した。DP-850SH と DP-1020SH のリモコン前面は、DP-700SH で既に型番 `RRMCG2009SCZZ` と確認済みのリモコン前面と、外形・ボタン数・ボタン配置・日本語ラベルが一致する。

これは3機種で同一のリモコン筐体／キー配列を採用していたことを強く示す。ただし、DP-850SH / DP-1020SH 側のリモコン裏面型番は今回確認できていないため、3機種すべてが `RRMCG2009SCZZ` そのものを共用した、あるいは赤外線コード表まで完全に同一だった、とまでは確定しない。

## 確認できた事実

### DP-850SH

2010-02-03のRBB TODAY製品写真には「DP-850SHのカラバリ・本体正面・背面とリモコン」と明記された写真が残る。

- https://www.rbbtoday.com/article/img/2010/02/03/65433/94806.html

また、現存するDP-850SH中古実物写真では、付属リモコン前面を比較的鮮明に確認できる。

- https://jp.mercari.com/item/m25489550689
- https://jp.mercari.com/item/m97201171439

確認できるキー配置は上から概ね以下。

- メニュー / ↑ / 電源
- ← / 決定 / →
- 戻る / ↓
- スライドショー / インデックス / モード切替
- 便利メニュー / 時計 / 絞り込み
- 縮小 / 拡大 / 回転

これはDP-700SHの `RRMCG2009SCZZ` 前面と一致する。

### DP-1020SH

DP-1020SH実機セットのYahoo!オークション写真では付属リモコン前面が明瞭に写っている。

- https://auctions.yahoo.co.jp/jp/auction/q1114485416

ここでも上記と同じ外形・キー配置・ラベルを確認できる。別のDP-1020SH中古出品ではリモコン用電池がCR2025と明記され、DP-700SHの `RRMCG2009SCZZ` と電池仕様も一致する。

- https://jp.mercari.com/item/m34411055966

## 確定事項

- DP-700SHの純正リモコン型番は `RRMCG2009SCZZ`（既知・裏面ラベル直接確認済み）。
- DP-850SHの実物付属リモコン前面は、DP-700SH `RRMCG2009SCZZ` と同じ外形・キー配置・ラベルを持つ。
- DP-1020SHの実物付属リモコン前面も、同じ外形・キー配置・ラベルを持つ。
- DP-1020SHの出品記録ではリモコン用電池がCR2025と記載され、DP-700SH純正リモコンと一致する。

## 状況証拠 / 推測

### 強い推測

3機種が同一または非常に近い赤外線リモコン設計を共用していた可能性は高い。2010年の3機種が同時系列の製品で、同日に共通内容のファームウェア更新を受け、ファームも `TH34` / `TH35` / `TH36` の連番で配布されていた既知事実とも整合する。

したがって、DP-700SHのIRコード探索で得られたコードはDP-850SH / DP-1020SHでも有効である可能性があり、逆に他2機種用リモコン実機を入手して受信解析することもDP-700SHコード表復元の有力な迂回路になる。

### まだ断定しないこと

- DP-850SH / DP-1020SHのリモコン裏面型番が `RRMCG2009SCZZ` であること。
- 3機種で搬送波周波数、プロトコル、アドレス、コマンド値が完全同一であること。
- 同じリモコン外観だからメイン基板やSoCまで同一であること。

## 実機調査への意味

`RRMCG2009SCZZ` の現物が見つからない場合でも、DP-850SHまたはDP-1020SH付属リモコンを入手し、受信器・ロジックアナライザ・Flipper Zero等で全キーを記録すれば、DP-700SHのコード表を復元できる可能性が高まった。

特にDP-70SHの隠しファーム書換え画面で使われた `拡大 → 縮小 → 時計 → 回転` の4キーは3機種の新型リモコンにも存在するため、コード取得後のDP-700SH隠し画面検証候補として維持する。
