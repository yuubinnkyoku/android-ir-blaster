# DP-700SH 調査追補 — SanJetの2009年商標指定商品に「デジタルフォトフレーム」

調査日: 2026-09-12 JST

## 新規根拠

台湾・経済部智慧財產局の公開データを転記する商標情報から、勝捷光電股份有限公司（SanJet）が **2009-06-26** に出願した商標「勝捷」（申請案號 `098027401`、登録番号 `01391873`）の第009類指定商品に、以下が明記されていることを確認した。

- 數位相機（デジタルカメラ）
- 數位相片播放器（デジタル写真プレーヤー）
- **數位相框（デジタルフォトフレーム）**
- 液晶顯示投影機
- 數位式攝影機
- MP3播放器
- 可攜媒體播放器
- ほか

登録日は2010-01-01。出願時の登録住所は `新竹市東區科學園區力行路21號4樓`。

出典:
- https://www.findcompany.com.tw/trademark/01391873_098027401
  - 同ページはデータ源を「經濟部智慧財產局公開資料」と明記。

## 確定事項

1. SanJetは、DP-700SH / DP-850SH / DP-1020SHの開発期間と重なる2009年6月の時点で、自社商標の指定商品として **デジタルフォトフレームを明示的に登録対象へ含めていた**。
2. 出願日は **2009-06-26**。既知のAIPTEK受託事業→SanJet承継（2009年6月）の直後に当たる。
3. 同じ指定商品群にはデジタルカメラ、デジタル写真プレーヤー、デジタルビデオカメラ、携帯メディアプレーヤー等も含まれ、当時のSanJetが画像・マルチメディア機器を事業領域として法的に押さえていたことが分かる。

## 状況証拠としての意味

既知の根拠には、AIPTEKの受託事業分離、AIPTEKのデジタルフォトフレーム知財が後にSanJetへ移転した記録、台湾側担当者の `Customer: AIPTEK` → `Customer: Sharp / FUJIFILM DP-850SH/DP-1020SH` という職歴がある。

今回の商標記録は、その間を補う独立資料になる。つまりSanJetは単に後年になって車載カメラ会社へ転じた企業ではなく、**2009年6月の組織再編直後からデジタルフォトフレームを自社の具体的な商品領域として掲げていた**。

このため、Sharp向けFUJIFILM DPF案件にSanJet側の開発資産・人員が関与したという仮説の整合性は一段上がる。

## 推測 / 断定禁止

- この商標記録だけでは、SanJetがDP-700SH / DP-850SH / DP-1020SHをODMしたことは証明できない。
- SharpからSanJetへの発注書、仕様書、BOM、基板番号、ソースコード等の直接資料は未発見。
- 「數位相框」が指定商品にあることは事業意図・事業領域の証拠であり、特定製品の製造実績そのものではない。
