# DP-700SH 調査追補 — 2026-09-04 07:35 JST

## 新規根拠: DP-7V の公式更新ファイルに `MP620` / `M622` が露出

FUJIFILM公式のDP-7Vファームウェア配布ページについて、Wayback Machineの2011-08-27保存版を復元した。ページはファーム更新に必要な3ファイルを明示している。

### 確定事項

- DP-7Vの更新には、以下の3ファイルをSDカードへ記録するよう公式ページで案内されていた。
  - `MP620.isp` — 13.7MB
  - `MP620.bin` — 910KB
  - `800X600DPF_M622_USB_UI_7D_100414_4Seasion.xpg` — 11.7MB
- 各ファイルの公式配布URLは以下。
  - `http://download.fujifilm.co.jp/pub/tools/DP7VQKtSfV3ojF/MP620.isp`
  - `http://download.fujifilm.co.jp/pub/tools/DP7VQKtSfV3ojF/MP620.bin`
  - `http://download.fujifilm.co.jp/pub/tools/DP7VQKtSfV3ojF/800X600DPF_M622_USB_UI_7D_100414_4Seasion.xpg`
- Wayback CDXで上記3バイナリの実体を検索したが、現時点では保存を確認できなかった。

出典:
- FUJIFILM公式DP-7V配布ページ（Wayback 2011-08-27 09:08:45）
  - https://web.archive.org/web/20110827090845id_/http://fujifilm.jp/support/digitalphotoframe/download/dp7v/download002.html
- DP-7V Ver.1.2.30公開記事（2010-08-03）
  - https://dc.watch.impress.co.jp/docs/news/385194.html

### 状況証拠

ファイル名 `800X600DPF_M622_USB_UI_7D_100414_4Seasion.xpg` は、少なくともビルド資産側で `800X600DPF`, `M622`, `USB`, `UI`, `100414` といった識別子が使われていたことを直接示す。`100414` は日付表記なら2010-04-14と読むのが自然だが、これは命名からの推測であり確定ではない。

また、`MP620.isp` / `MP620.bin` と `...M622...xpg` が同一更新セットに含まれるため、DP-7Vの更新・ソフトウェア資産には `MP620` / `M622` という内部識別子が現れることは確実である。

### 2026-09-04 09:45追記: `MP620` はDP-7V固有識別子ではない

追加調査で、第三者の旧ドライバ/ファームウェア保存サイト TousLesDrivers が、FUJIFILM **FinePix REAL 3D V1** のファームウェア Ver.2.00 の実ファイル名として **`mp620.isp`** を記録していることを確認した。同ページはファイルサイズを約2.9MB、FUJIFILM側の公開日を2009-11-30としている。

出典:
- TousLesDrivers — Firmware Fujifilm FinePix REAL 3D V1 2.00
  - https://www.touslesdrivers.com/index.php?v_code=26677&v_langue=en&v_page=23
- Web検索で同じFUJIFILM配布ファイルを指すWayback参照記録も確認したが、今回は第三者保存ページを補助証拠として扱う。

**確定:** `MP620.isp` というファイル名はDP-7Vだけに固有ではなく、少なくともFinePix REAL 3D V1でも使用されていた。

**重要な修正:** したがって、`MP620` をDP-7V固有の「基板番号」「SoC番号」「案件番号」とみなす根拠は弱い。少なくともFUJIFILM製品をまたいで再利用される更新モジュール名・プラットフォーム名・ビルドターゲット名などの可能性も考える必要がある。

**未確定:** DP-7Vの13.7MB `MP620.isp` とFinePix REAL 3D V1の約2.9MB `mp620.isp` が同一形式・同一SoC系列・同一開発ツール由来かどうか。ファイル名一致だけでは共通ハードウェアを証明しない。

### DP-700SH調査への意味

DP-7VはDP-700SHと時期が近いFUJIFILM製デジタルフォトフレームだが、DP-700SH系列の更新形式は `TH34_dpf.pkg` / `TH35_dpf.pkg` / `TH36_dpf.pkg` である。先代DP-70SHは `TH180700.ver`、後継DP-701SH/DP-801SHは `TH50_dpf.pkg`。

今回のDP-7V資料により、FUJIFILMのDPF全体が単一の `THxx` 更新基盤で連続していたという見方は成立しない。少なくともDP-7Vは、公式配布ファイルの構成と命名が明確に別系統だった。

一方で今回のFinePix REAL 3D V1とのファイル名一致により、`MP620` 自体をDP-7V固有のハードウェア識別子と読むのは避けるべきとなった。DP-700SH/850SH/1020SHの `TH34/35/36` が特定の共通開発基盤を示す可能性は残るが、比較対象の `MP620/M622` の意味は以前より不確実になった。

### 未確定

- `MP620` / `M622` のベンダー。
- `.isp` / `.bin` / `.xpg` の内部形式。
- DP-7VとFinePix REAL 3D V1がSoC・OS・開発ツールを共有するか。

- DP-700SH系列の `TH34/35/36` とDP-70SH `TH18`、後継 `TH50` の番号意味。

現段階では `MP620/M622` を特定ベンダーやSoCへ結び付けない。
