# DP-700SH 調査追補 — DP-70SH公式ファーム実体回収と `SHARP_PF100_PLATFORM`

調査日時: 2026-09-15 JST

## 確定事項

### DP-70SH公式ファーム `TH180700.ver` の実バイナリがWayback Machineに保存されている

FUJIFILM公式配布URLをWayback MachineのCDXで完全一致検索したところ、次の2保存を確認した。

- 2016-06-23 11:31:10 UTC — HTTP 200 / `application/octet-stream`
- 2016-06-24 12:40:00 UTC — HTTP 200 / `application/octet-stream`

元URL:
- http://download.fujifilm.co.jp/pub/tools/dp70sh/TH180700.ver

保存版:
- https://web.archive.org/web/20160623113110id_/http://download.fujifilm.co.jp/pub/tools/dp70sh/TH180700.ver
- https://web.archive.org/web/20160624124000id_/http://download.fujifilm.co.jp/pub/tools/dp70sh/TH180700.ver

2026-09-15に前者をraw (`id_`) で取得し、バイナリ内容が実際に返ることを確認した。したがって、従来メモの「`TH180700.ver` 本体はWaybackに保存されていない」という記述は誤りで、訂正が必要。

### バイナリ内部に `SHARP_PF100_PLATFORM` が存在する

raw取得した `TH180700.ver` 内で、少なくとも次のASCII文字列を直接確認した。

- `SHARP_PF100_PLATFORM`
- `FW Revision: V%d.%02d`
- `NEW SERIAL FLASH`
- `BOOT`
- `NVRAM`
- `NVRAM_2`
- `ROMTAB`
- `STRTAB`
- `FIRMWARE`
- `VERSION`
- `CHECKSUM`
- `SPI`
- `MXIC`
- `ATMEL`
- `erase`
- `prog`
- `boot_comm`
- `TaskMgr`
- `task switching..`
- `SliceCycles:`
- `main clk %d`
- `13:21:49 Apr 23 2009`

USB制御系のデバッグ文字列も多数残っており、`USBHS_ENABLE`, `RequestType`, `Descriptor`, `SETUP REQ`, `Device`, `Remote Wakeup`, `Get Configuration`, `Endpoint Halt` 等を確認できる。

**確定:** 少なくとも先代DP-70SHの公式更新バイナリは、Sharp名を含む `SHARP_PF100_PLATFORM` というプラットフォーム識別子/ビルド定義を内部に持つ。

**確定:** ファーム内にはブート、NVRAM、文字列表、ファーム本体、版数、チェックサムとみられる区画名、およびSerial Flash/SPI/USB/タスク制御に関するコード・デバッグ文字列が含まれる。

## 状況証拠・推測

### `PF100` はSharp側のデジタルフォトフレーム製品プラットフォーム名である可能性

`SHARP_PF100_PLATFORM` はファーム内部に直接存在するため、「DP-70SHのソフトウェア基盤にSharpが深く関与した」という根拠として、銘板・液晶・リモコン等の外形情報より一段強い。

一方、`PF100` が何を意味するかは未確認。候補はSharp社内の製品プラットフォーム名、基板/SoC抽象化層のビルド定義、案件コードなど。

2026-09-15時点の公開GitHubコード検索では `SHARP_PF100_PLATFORM` の一致は0件で、一般公開SDKの既知名称とは確認できなかった。

### OS/RTOSはまだ特定できない

`TaskMgr`, `task switching..`, `SliceCycles:` などから、タスク切替を持つ組込み実行環境が存在することは分かる。しかし、FreeRTOS / ThreadX / Nucleus / μITRON等の固有名は今回確認できていない。

したがって、**RTOS利用の可能性はあるがOS名は未確定**とする。

### DP-700SH世代との比較価値

DP-70SHからDP-700SHへの系列継承は既知だが、2010年世代が同じ `PF100` 基盤を継承した証拠はまだない。

今後 `TH34_dpf.pkg` / `TH35_dpf.pkg` / `TH36_dpf.pkg` のいずれかを回収できれば、まず以下の文字列・構造を比較する価値が高い。

- `SHARP_PF100_PLATFORM` / `PF100`
- `BOOT`, `NVRAM`, `ROMTAB`, `STRTAB`, `FIRMWARE`, `VERSION`, `CHECKSUM`
- Serial Flashベンダ (`MXIC`, `ATMEL`)
- USBスタック由来文字列
- タスク管理・デバッグ文字列
- ビルド日時形式

## 断定禁止

今回の発見だけから、以下は断定しない。

- DP-700SH / DP-850SH / DP-1020SHも `PF100` プラットフォームである。
- DP-70SHと2010年3機種が同じSoCを搭載する。
- `PF100` がSoC型番である。
- DP-70SHがITE / SMedia系SoCを搭載する。
- `TaskMgr` 等の文字列から特定RTOS名を決め打ちする。
