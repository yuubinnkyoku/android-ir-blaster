# DP-700SH 調査追補 2026-09-05 09:17 JST

## 新規根拠: 前身 DP-70SH のファーム更新UI/保守操作

### 確定事項

デジカメ Watch の2009-04-01記事により、FUJIFILMの初代Sharp ASV液晶採用デジタルフォトフレーム `DP-70SH` には、2009-03-31に **Ver.1.04.00** のファームウェア更新が公開されていたことを確認した。

更新方法は、フォーマット済みSDカードにファームウェアを保存し、設定メニューの「本体情報の表示」→「バージョン表示」を開いた状態で、純正リモコンの

`拡大 → 縮小 → 時計 → 回転`

を順に押すと「ファームウェア書き換え画面」へ移る、という隠し操作だった。

出典:
- デジカメ Watch「富士フイルム、7型デジタルフォトフレームのファームウェアを公開」(2009-04-01)
  - https://dc.watch.impress.co.jp/cda/accessories/2009/04/01/10602.html

同記事および同時代資料から、DP-70SHは以下を備えていたことも確認できる。

- Sharp製ASV液晶 7型 800×480
- IrSimple / IrSS
- 明るさセンサー
- CF / SD(SDHC) / Memory Stick / xD 系メモリカード対応

参考:
- https://dc.watch.impress.co.jp/cda/item/2009/05/08/10786.html
- https://www.itmedia.co.jp/news/article/0902/04/1090204098/

### DP-700SHとの関係で確定できること

DP-700SHの純正リモコン `RRMCG2009SCZZ` にも `拡大` / `縮小` / `時計` / `回転` の各キーが存在することは既に実物写真から確認済みである。

したがって、FUJIFILMのSharp液晶DPF系列では、少なくとも2009年のDP-70SH時点から、後年のDP-700SHで残る同名キー群をファーム更新の保守入口に利用するUI設計が存在していた。

### 状況証拠・推測

DP-70SHは、2010年のDP-700SH / DP-850SH / DP-1020SHより一世代前のSharp液晶採用機であり、DP-700SHとは画面サイズ・解像度・IrSimple・明るさセンサー・カード対応など多くが重なる。

このため、DP-700SH系のソフトウェア/UIが完全な新規設計ではなく、DP-70SH系から継承・発展した可能性が高まる。特に、`本体情報の表示` / `バージョン表示` とリモコンの同名キー群が保守操作に使われる構造は、ソフトウェア系譜を追う手掛かりになる。

ただし、以下は未確定である。

- DP-70SHとDP-700SHが同一SoCまたは同一メイン基板を採用したこと
- DP-70SHの更新ファイル形式/ファイル名が `THxx_dpf.pkg` 系だったこと
- DP-700SH / DP-850SH / DP-1020SHでも同じ `拡大→縮小→時計→回転` がファーム更新入口であること
- DP-70SHとDP-700SHのリモコン赤外線プロトコル/アドレス/キーコードが共通であること

バージョン番号がDP-70SHでも `1.04.00` だった点は興味深いが、DP-700SHの公開版 `1.04.00` と番号が同じことだけで同一コードベースと断定してはいけない。
