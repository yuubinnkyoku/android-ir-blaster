# DP-700SH 調査追記 — 2026-09-17 19:37 JST

## 新規に確認できた事実

### 翌2011年世代 DP-701SH / DP-801SH は「同一ファームウェア」を共用

2011-07-29のデジカメ Watch記事で、FUJIFILMがDP-701SH / DP-801SH向けにVer.1.04.07を公開し、記事本文が明確に「ファームウェアは両機種で共通」と記していることを確認した。

更新内容:
- 内蔵メモリーの写真をスライドショー再生すると、まれに停止する症状を修正
- 赤外線通信の対応機種を追加
- より大容量のメモリーカードに対応
- 動画再生をよりなめらかにする

出典:
- デジカメ Watch, 2011-07-29: https://dc.watch.impress.co.jp/docs/news/464018.html
- 記事が示す旧FUJIFILM公式ダウンロードページ: http://fujifilm.jp/support/digitalphotoframe/download/dp701sh_dp801sh/download001.html

DP-701SH / DP-801SHはともに800×480の7型/8型モデルで、IrSS、高速赤外線通信、JPEG、Motion JPEG、WAV/MP3等に対応していた。

## 既存のDP-700SH系列との比較

### 確定事項

2010年世代のDP-700SH / DP-850SH / DP-1020SHでは、同じIrSimple / IrSS / IrDA不具合を同日に修正している一方、公式配布ファイルは機種別に `TH34_dpf.pkg` / `TH35_dpf.pkg` / `TH36_dpf.pkg` と分かれていた。

それに対し、翌2011年世代のDP-701SH / DP-801SHでは、公開記事が明示的に「ファームウェアは両機種で共通」としている。

### 状況証拠・推測

この差は、FUJIFILM/Sharp系デジタルフォトフレームのソフトウェア構成が、少なくとも2011年世代では7型/8型を単一ファームで吸収できる構成になっていたことを示す。

2010年の `TH34/35/36` が別ファイルだった理由については、(a) 同一コード基盤から機種別設定を焼き込んだだけ、(b) 画面・メモリ・動画/音声機能差に応じて別ビルドが必要だった、(c) SoC/基板差があった、のいずれもまだ排除できない。

### 断定しないこと

- DP-701SH / DP-801SHがDP-700SH / 850SH / 1020SHと同じSoC、OS、基板を使う証拠にはならない。
- 2011年世代がSharp製であることも、この資料だけでは確定しない。
- `SH` suffixだけからSharp設計・製造を推定しない。
- 2011年共通ファームの実ファイル名・バイナリ本体は今回未回収。

## 次に照合する価値が高いもの

2011年DP-701SH/801SHの公式ファーム本体を回収できれば、DP-70SH `TH180700.ver` で確認済みの `SHARP_PF100_PLATFORM`, `BOOT`, `NVRAM`, `ROMTAB`, `STRTAB`, `boot_comm` 等を検索する。2010年 `TH34/35/36_dpf.pkg` が未回収でも、世代間でSharp系ファーム基盤が継続したかを間接的に検証できる可能性がある。
