# DP-700SH evidence — 2026-09-20 09:39 JST

## 新しい根拠: Sharpの近縁デジタル写真機器でeCROS / PrKERNELv4を確認

### 確定事項

2009-05-12、イーソルはSharpが開発したAQUOSフォトプレーヤー `HN-PP100` / `HN-PP150` に組み込みソフトウェア基盤 **eCROS** が採用されたと発表している。

採用構成は具体的に以下まで公開されている。

- μITRON4.0仕様準拠RTOS **PrKERNELv4**
- 開発ツール **eBinder**
- ファイルシステム
- SDメモリーカード / メモリースティック等のメディアドライバ
- USBホストスタック

Sharp公式仕様でもHN-PP100は、SD/MS、CompactFlash、USB、IrSS、専用赤外線リモコン、写真スライドショーを備える。これはDP-70SH / DP-700SH系列と周辺I/O・用途がかなり重なる。

出典:
- https://www.esol.co.jp/archive/news/emb_press090512.html
- https://www.value-press.com/pressrelease/38910
- https://jp.sharp/products/av/photoplayer/prod01/hnpp100w/index.html
- https://jp.sharp/support/photoplayer/doc/lineup.html

### さらに重要なファームウェア命名規則

Sharp公式のHN-PP150更新手順には、更新ファームウェア名として **`TH150400.ver`** が明記されている。Sharp公式ダウンロードページでは容量 **121MB**、対象は本体FW `1.03.01.04` 以下。

出典:
- https://jp.sharp/support/photoplayer/doc/how_to_update.pdf
- https://jp.sharp/support/photoplayer/fw_agree.html

既に回収済みのDP-70SHファーム名 `TH180700.ver` と同じ **`TH... .ver`** 命名体系が、Sharp自社のAQUOSフォトプレーヤーでも使われていたことになる。

一方、DP-700SH / DP-850SH / DP-1020SHのFUJIFILM配布物は `TH34_dpf.pkg` / `TH35_dpf.pkg` / `TH36_dpf.pkg`。拡張子は違うが、`TH` 接頭辞はSharp側の近縁製品群でも確認できる。

## 推測・評価

### OS候補の優先順位を変更

**有力候補として追加:** DP-70SH / DP-700SH系列もeCROS系、特にPrKERNELv4または同系統のT-Kernel/μITRON基盤を使っている可能性。

理由:

1. HN-PP100/150はSharp自身が開発した同時代（2008末〜2009）のデジタル写真機器。
2. SD/MS/CF、USB、IrSS、赤外線リモコン、写真スライドショーという周辺機能がDP-70SH/700SH系列と大きく重なる。
3. eCROS採用発表は、Sharpが上位アプリ開発へ集中し、短期・低コスト化するために共通ソフトウェア基盤を使ったと説明している。
4. Sharp HN-PP150の更新ファイル `TH150400.ver` と、FUJIFILM DP-70SHの `TH180700.ver` に命名上の共通性がある。

ただし、**DP-700SHでeCROS/PrKERNELv4が採用された直接証拠ではない**。`TH` 接頭辞だけで同一ブートローダ/OS/SoCを断定しない。

### 次の検証ポイント

DP-70SHの回収済み `TH180700.ver` および将来回収できた `TH34_dpf.pkg` で、以下の文字列を優先探索する価値がある。

- `PrKERNEL`
- `eCROS`
- `eBinder`
- `eSOL`
- T-Kernel / μITRON由来のAPI・タスク/セマフォ関連文字列
- eSOLのファイルシステム、USB、メディアドライバ由来の識別子

HN-PP150の `TH150400.ver` を合法的に取得できる環境では、コンテナ構造・ヘッダ・`TH`命名規則の比較資料として価値が高い。ただしSharp配布ページの使用許諾にはリバースエンジニアリング禁止条項があるため、扱いはライセンス条件を確認して分離する。
