# DP-700SH 追加証拠 — 2026-09-11 18:43 JST

## 結論

2010年2月の発売時報道に掲載されたFUJIFILM提供系の商品写真で、**DP-1020SH / DP-850SH / DP-700SHの3機種すべてに、同じ外観・同じボタン配列の専用リモコンが写っている**ことを確認した。

既存調査では、DP-700SH実機出品の裏面写真から純正リモコン型番 `RRMCG2009SCZZ` を直接確認し、中古流通上では同型番がDP-850SH/DP-1020SH対応として扱われる例を確認していた。今回の資料は、発売時点の製品写真でも3機種のリモコン外観が共通だったことを補強する。

## 確定事項

### DP-700SH純正リモコンの型番は `RRMCG2009SCZZ`

Yahoo!オークションのDP-700SH実機セット写真では、リモコン裏面ラベルを判読できる。

- `REMOTE CONTROL UNIT`
- `RRMCG2009SCZZ`
- `使用電池 リチウム電池 CR2025 1個`
- `FUJIFILM Corporation`

出典:
- https://auctions.yahoo.co.jp/jp/auction/q1171811726

この事項自体は既存ログにも記録済み。

### 3機種の発売時商品写真ではリモコン前面が同一外観

RBB TODAYの2010-02-03掲載記事は、3機種について以下のキャプション付き商品写真を掲載している。

- `DP-1020SHの本体正面・背面とリモコン`
  - https://www.rbbtoday.com/article/2010/02/03/65433.html
- `DP-850SHのカラバリ・本体正面・背面とリモコン`
  - https://www.rbbtoday.com/article/img/2010/02/03/65433/94806.html
- `DP-700SHのカラバリ・本体正面・背面とリモコン`
  - https://www.rbbtoday.com/article/img/2010/02/03/65433/94807.html

写真上のリモコンはいずれも、FUJIFILMロゴ、右上の赤い電源キー、中央の十字キー、下段の機能キーを含め、同じ筐体・同じキー配置に見える。

## 状況証拠としての意味

**有力:** DP-700SH / DP-850SH / DP-1020SHは、少なくともリモコンUIと受信側のキー集合を共通化していた可能性が高い。

これは次の既知情報とも整合する。

- 3機種は2010-04-30に同じIrSimple/IrSS/IrDAハング不具合の修正を同時に受けた。
- 更新ファイルも `TH34_dpf.pkg` / `TH35_dpf.pkg` / `TH36_dpf.pkg` と連番だった。
- DP-850SH / DP-1020SHは台湾側公開職歴上で同一開発案件として記載される。

したがって、IRコード探索では**DP-850SH / DP-1020SH由来のリモコンコードが見つかった場合、DP-700SHへ流用できる可能性を従来より高く見積もれる**。

## 断定しない事項

- DP-850SH / DP-1020SHのリモコン裏面で `RRMCG2009SCZZ` そのものを読める一次写真は今回まだ得られていない。
- 外観が同じでも内部基板・発振子・IR方式・機種別コードが完全同一とは限らない。
- したがって現時点では「3機種すべての純正リモコン型番がRRMCG2009SCZZ」とは断定しない。
- また、リモコン共通化だけからSoCやメイン基板の完全共通化は導けない。
