# DP-700SH 調査ログ — 2026-09-03

## 今回確認した新規根拠

天擎積體電路（Mars Semiconductor）の2019年株主総会年報の会社沿革を確認。

- 2001年2月: `DSC / DV / 電子相框 / PC相機` 向け開発へ注力。
- 2008年（民国97年）: **奇景光電（Himax）のSoCチームを統合し、MPEG-4を開発**。

出典:
- https://www.mars-semi.com.tw/wp-content/uploads/2021/09/108%E5%B9%B4%E8%82%A1%E6%9D%B1%E6%9C%83%E5%B9%B4%E5%A0%B1.pdf

既知の企業紹介では天擎の顧客例に天瀚科技（AIPTEK）が挙げられている。
- https://108976.web66.tw/

DP-850SH / DP-1020SHはMPEG-4 SP再生対応で、Sharp向け案件開始（2009年）より前にMars側でMPEG-4 SoC技術が存在していたことになる。
- https://dc.watch.impress.co.jp/docs/news/346441.html

### 判定

**状況証拠として追加。搭載SoCの確定には使わない。**

AIPTEKとの顧客関係、DPF向けSoC事業、2008年のMPEG-4技術獲得は、MarsをSoC候補として追う理由を補強する。しかしDP-700SH/850SH/1020SHの基板写真・SoC刻印・ファーム内識別子がないため採用実績は未証明。

## 追加探索: `MR7910 / MR791x`

Mars Semiconductorの写真表示機器向け具体型番を追跡したところ、`MR7910` 系統の実在を複数経路で確認した。

- Uniden `UDV-15` の分解記事:
  - 基板 `15B1A-MB Ver 1.2`
  - 基板日付 `2007-11-23`
  - メイン制御ICはCOBで刻印不可
  - USB `VID 093A / PID 020F`
  - OEMドライバ `mr7910.sys` v2.5 / Mars Semiconductor Corp.
  - 操作ソフト `mr7910.exe`
  - https://goughlui.com/2020/06/28/tech-flashback-uniden-udv-15-digital-photo-viewer/
- Mars Semiconductor `Photo Viewer`:
  - `C:\Program Files\Mars\MR7910\`
  - `mr7910.exe`, `mr7911.exe`, `mr7912.exe`, `MR7911.dll` など
  - https://www.shouldiremoveit.com/Photo-Viewer-32226-program.aspx
- TAO Image Transfer:
  - 同じ `MR7910` ディレクトリ

  - https://www.shouldiremoveit.com/TAO-Image-Transfer-11341-program.aspx
- Brookstone Image Transfer:

### 判定

**Marsが2007〜2008年頃に写真表示機器向け `MR7910/MR791x` 系統を実際に展開していたことはかなり強く確認できた。ただしDP-700SH系列への搭載証拠ではない。**

Uniden個体ではIC刻印がCOBで見えず、`mr7910` というドライバ/ソフト名と流通IC型番を直接同一個体上で結びつける刻印証拠はない。また `VID 093A` はPixArt Imagingとして登録される資料もあるため、USB VIDからMars/PixArtの関係を推定しない。

今後の基板・ファーム照合語に `MR79xx`, `MR7910`, `MR7911`, `MR7912`, `Mars` を追加する。
