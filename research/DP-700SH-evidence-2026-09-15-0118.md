# DP-700SH evidence — 2026-09-15 01:18 JST

## 新しく確認できた根拠

### 1. `RRMCG...` はSharp自身が使うリモコン型番系列

Sharp公式のプロジェクター `PG-C30XU` 取扱説明書には、付属リモコンのラベルとして **`REMOTE CONTROL MODEL NO. : RRMCG1579CESA`** が掲載されている。

出典:
- Sharp公式 `PG-C30XU` manual PDF: https://global.sharp/products/pdf/pg-c30x/manuals/usa/c30_usp.pdf
- Web検索で確認した該当記載: `REMOTE CONTROL MODEL NO. : RRMCG1579CESA`

さらにSharp用交換リモコン市場には `RRMCG0056SJSA`, `RRMCG0004AWSA`, `RRMCG0033AWSA`, `RRMCG1051BMSA` など多数のSharp純正/互換型番が残っている。

出典例:
- https://egyeb-hifi-kiegeszito.arukereso.hu/general/sharp-rrmcg0056sjsa-kompatibilis-general-markaju-taviranyito-p1090563127/
- https://egyeb-hifi-kiegeszito.arukereso.hu/general/sharp-rrmcg0004awsa-kompatibilis-general-markaju-taviranyito-p1167800440/
- https://www.remote-controls-shop.co.uk/catalogue/sharp/rrmcg1051bmsa/cmb1584/

**確定事項:** `RRMCG` は少なくともSharp製品で実際に使われるリモコン型番系列である。

**状況証拠:** DP-700SH純正リモコンの `RRMCG2009SCZZ` は、FUJIFILM独自のランダムな型番というより、Sharp側の部品/リモコン命名体系に属する可能性が高い。DP-700SH本体銘板の「製造元: シャープ株式会社」と整合する。

**断定しないこと:** `RRMCG` という接頭辞だけで、赤外線プロトコルがSharp 15-bit方式だとは確定できない。Sharpの製品群には年代・カテゴリごとに異なるIR方式があり得るため、`RRMCG2009SCZZ` 自体の波形取得または実機反応が必要。

### 2. 先代DP-70SHのリモコン前面は2010年リモコンと強い連続性がある

DP-70SHの中古実機写真・レビュー写真で、付属リモコン前面を確認した。ボタンは次の15個:

- メニュー
- 上 / 下 / 左 / 右
- 決定
- 電源
- 戻る
- スライドショー
- インデックス
- モード切替
- 拡大
- 縮小
- 時計
- 回転

出典:
- デジカメWatch DP-70SHレビュー: https://dc.watch.impress.co.jp/cda/item/2009/05/08/10786.html
- Mercari DP-70SH用リモコン写真: https://jp.mercari.com/item/m55155441972

2010年の `RRMCG2009SCZZ` は、上記15ボタンをすべて維持したうえで、**`便利メニュー` と `絞り込み` の2ボタンを追加した17ボタン構成**になっている。

比較対象:
- Yahoo!オークション/フリマ `RRMCG2009SCZZ` 写真: https://auctions.yahoo.co.jp/jp/auction/g1043790009
- https://paypayfleamarket.yahoo.co.jp/item/g1043790009

**確定事項:** DP-70SH → DP-700SH世代で、リモコンの主要15操作は前面配置も含めてほぼそのまま継承され、2010年側で2機能が追加されている。

**状況証拠:** これは2009年DP-70SHと2010年DP-700SH/850SH/1020SHのユーザーインターフェースおよびリモコン制御系が、完全新規ではなく前世代を発展させた可能性を補強する。

**未確認:** DP-70SHリモコンの背面型番、DP-70SHと`RRMCG2009SCZZ`のIRコード互換性。外観・ボタン継承だけでは赤外線コードの一致は証明できない。

## 実機調査への含意

`RRMCG` がSharp自身のリモコン型番系列であることが一次資料で確認できたため、現在行っているSharp系IR探索は以前より根拠が強くなった。ただし、Sharp 13-bit探索だけに限定する根拠にはまだならない。

DP-70SH純正リモコンを入手できる場合、共通15キーのどれか1つでも波形を取得し、`RRMCG2009SCZZ`/DP-700SHで反応するか比較する価値が高い。共通コードなら、2009→2010の制御系継承をかなり強く示せる。
