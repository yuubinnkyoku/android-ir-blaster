# DP-700SH 調査追補 — 2026-09-12 02:43 JST

## 新規根拠: 先代DP-70SHの公式ファーム実ファイル名を回収

Wayback Machineに保存されたFUJIFILM公式のDP-70SHファームウェア配布ページを差分取得し、使用許諾後のダウンロードページ `download002.html` のHTMLを直接確認した。

### 確定事項

2010-02-04および2010-02-05保存の公式ページには、DP-70SH用ファームとして次が明記されている。

- ファイル名: **`TH180700.ver`**
- 容量: **1.9MB**
- HTTP: `http://download.fujifilm.co.jp/pub/tools/dp70sh/TH180700.ver`
- FTP: `ftp://download.fujifilm.co.jp/pub/tools/dp70sh/TH180700.ver`

出典:
- Wayback保存対象: `http://fujifilm.jp/support/digitalphotoframe/download/dp70sh/download002.html`
- 保存時刻: 2010-02-04 00:37:17 / 2010-02-05 03:52:14
- https://web.archive.org/web/20100204003717/http://fujifilm.jp/support/digitalphotoframe/download/dp70sh/download002.html

同じ公式更新ページ `download001.html` の2010-01-30および2010-03-03保存版では、最新ファームを **Ver.1.07.00** と明記している。

また更新履歴として少なくとも次の版が公式HTML中に現れる。

- Ver.1.03.00 → Ver.1.04.00
- Ver.1.04.00 / Ver.1.06.00 → Ver.1.07.00

更新手順PDFは `/support/pdf/digitalphotoframe/manual/ff_dp70sh_firmware_mn_j.pdf`、表示容量294KB。

出典:
- https://web.archive.org/web/20100130172650/http://fujifilm.jp/support/digitalphotoframe/download/dp70sh/download001.html
- https://web.archive.org/web/20100303071503/http://fujifilm.jp/support/digitalphotoframe/download/dp70sh/download001.html
- 2009-04-01時点のVer.1.04.00公開記事: https://dc.watch.impress.co.jp/cda/accessories/2009/04/01/10602.html

### DP-700SH世代との比較 — 確定

既知の2010年世代は:

- DP-700SH: `TH34_dpf.pkg` — 2.1MB
- DP-850SH: `TH35_dpf.pkg` — 2.2MB
- DP-1020SH: `TH36_dpf.pkg` — 2.2MB

先代DP-70SHは `TH180700.ver` であり、**同じ `TH` 接頭辞を使う一方、命名規則と拡張子が `.ver` → `_dpf.pkg` へ変化している**。

したがって、DP-70SHからDP-700SHへUIや隠し更新操作が継承されている可能性と、更新パッケージ層そのものが同一であることは分けて考える必要がある。少なくとも公開配布形式は同一ではない。

### 状況証拠 / 推測

`TH180700.ver` の末尾 `0700` がVer.1.07.00を符号化している可能性は高い。また `TH18` が機種・基盤・ビルド系列を表す可能性がある。しかし、命名仕様書や別版の実ファイル名をまだ回収できていないため確定しない。

DP-70SHの更新UI（本体情報→バージョン表示→拡大→縮小→時計→回転）とDP-700SHのUI/キー構成の類似は引き続き実機検証価値がある。ただし、今回 `.ver` と `.pkg` の差が直接確認できたため、同じ更新画面へ入れたとしても同一ブートローダ・同一パーサ・同一SoCを意味しない。

### 未回収

- `TH180700.ver` バイナリ本体。Wayback CDXで上記実URLを検索したが保存は確認できない。
- Ver.1.04.00 / 1.06.00時点の実ファイル名。`TH180700.ver` から過去版名を推測しない。
- `TH34_dpf.pkg` / `TH35_dpf.pkg` / `TH36_dpf.pkg` 本体。

## 補助的な新規確認

### DP-70SHも銘板上の製造元がSharp

中古実機の背面銘板写真で、先代DP-70SHについても `販売元: 富士フイルム株式会社` / `製造元: シャープ株式会社` / `MADE IN CHINA` を確認できる。価格.comの当時利用者レビューにも「製造元もシャープ」とする独立した実機記述が残る。

参考:
- https://review.kakaku.com/review/K0000019109/ReviewCD=421924/

**意味:** 2009年DP-70SH → 2010年DP-700SH/850SH/1020SHでSharpが完成品製造元として続く系列性を補強する。ただしDP-70SHは12V系、2010年世代は5V系であり、電源/基板まで同一設計とはみなさない。

### DP-850SH / DP-1020SHは共通の使用説明書

DP-1020SH中古一式の写真で、冊子表紙に **`DIGITAL PHOTO FRAME DP-850SH / DP-1020SH 使用説明書`** と両型番が併記されていることを確認した。同じ写真には2010年系列と同外観のリモコンも写る。

参考:
- https://auctions.yahoo.co.jp/jp/auction/o1098196199

**確定:** 少なくとも850SH/1020SHは一冊の共通使用説明書を使うほど操作体系・機能説明を共通化していた。

**断定禁止:** 共通説明書は同一メイン基板・同一SoC・同一ファームウェアバイナリの証拠ではない。
