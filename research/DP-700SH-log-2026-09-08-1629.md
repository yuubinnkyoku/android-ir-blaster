## New finding
AIPTEK's 2007 patent family for a digital photo frame with photographing function was found to disclose an internal architecture containing a display module, memory module, control module, input module, power module and sensing module. The input module explicitly includes a **wireless receiving module and a remote controller**.

Key family:
- CN201119657Y — https://patents.google.com/patent/CN201119657Y/en
- US20090059052A1 / US7986368B2 — https://eureka.patsnap.com/patent-US20090059052A1

Inventors:
- 林烈诚 / Lien-Chen Lin
- 郑平溥 / Ping-Fu Cheng
- 张正伦 / Chen-Loon Chang

Interpretation: this is direct evidence that AIPTEK's DPF engineering base already covered remote-control wireless reception and sensor integration before the SanJet split. It adds technical depth to the previously established AIPTEK→SanJet organizational/IP continuity, but does not prove that the same circuitry/software was used in FUJIFILM DP-700SH/850SH/1020SH.

## Evidence separation
- **Confirmed:** the AIPTEK patent discloses a DPF with a sensing module and an input module containing wireless reception + remote controller.
- **Inference:** subsystem know-how of this type may have been part of the engineering base that later moved toward SanJet ODM work.
- **Not established:** shared SoC, shared OS, shared PCB, shared IR protocol, shared source tree, or direct use of this patent implementation in FUJIFILM DP series.
