# DP-700SH 追加根拠 — 2026-09-11 11:03 JST

## AIPTEK → SanJet の知財移管を米国特許でも確認

Google Patents の米国特許 **US7039230B2**（`Method for compressing an image by using characteristic values`）の法的イベントを確認した。

### 確定事項

- 元の権利者: **AIPTEK INTERNATIONAL INC., TAIWAN**
- 現在の権利者表示: **SANJET TECHNOLOGY CORP.**
- 2010-08-25 の Assignment 記録に、
  - `ASSIGNOR: AIPTEK INTERNATIONAL INC.`
  - `Owner name: SANJET TECHNOLOGY CORP., TAIWAN`
  - `REEL/FRAME: 024906/0324`
  - **Effective date: 2010-08-05**
  が明記されている。
- 対象特許は画像データの圧縮・メモリ格納量増加を目的とする画像処理技術で、デジタル画像機器に関係するが、DP-700SH固有の特許ではない。

出典:
- https://patents.google.com/patent/US7039230B2/en

## 既知のDPF特許移管との接続

既に確認済みの中国実用新案 **CN201153780Y**（可替换多种框体的数位相框组）では、AIPTEK/天瀚科技からSanJet/勝捷光電への権利移転登録実効日が **2010-09-19**。

出典:
- https://patents.google.com/patent/CN201153780Y/zh

したがって、少なくとも公開特許記録上は、

- **2010-08-05:** 米国の画像処理特許が AIPTEK → SanJet
- **2010-09-19:** 中国のデジタルフォトフレーム特許が AIPTEK → SanJet

と、2010年夏〜秋に複数法域・複数技術領域でAIPTEKの知財がSanJetへ正式移管されていることが確認できる。

## 状況証拠としての意味

これは、2009-06-01のODM事業承継が会社登記上の資本・人員だけでなく、後追いで**画像処理およびデジタルフォトフレーム関連の知財ポートフォリオ移管を伴っていた**ことを補強する。

既知の台湾側職歴 `2009-10〜2010-02: FUJIFILM DP-850SH/DP-1020SH / Customer: Sharp` の完了後数か月で、AIPTEKからSanJetへの正式な知財移転が続いている時系列になる。

## 断定禁止

- US7039230B2 が DP-700SH / DP-850SH / DP-1020SH に実装された証拠はない。
- この特許移管から、SanJetがSharp向けFUJIFILM DPシリーズのODMだったと単独で断定してはならない。
- 2010-08-05という移管日がSharp案件完了後であることは、案件の開発時点ですでにSanJetが当該特許を法的に所有していたことを意味しない。
