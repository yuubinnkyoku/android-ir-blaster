# DP-700SH 調査追補 — RRMCG2009SCZZ の2010年3機種共通性

調査日時: 2026-09-08 JST

## 新たに確認できた根拠

### 確定度: 中〜高 — DP-850SH / DP-1020SH でも DP-700SH と同じ外観のリモコンが付属

中古実機一式の写真で、DP-850SH と DP-1020SH のそれぞれに、DP-700SH純正 `RRMCG2009SCZZ` と前面の形状・キー配置が一致するFUJIFILMリモコンが付属していることを確認した。

- DP-850SH 実機一式写真: https://jp.mercari.com/item/m97201171439
- DP-1020SH 実機一式写真: https://auctions.yahoo.co.jp/jp/auction/j1048872798
- `RRMCG2009SCZZ` 前面・背面写真: https://auctions.yahoo.co.jp/jp/auction/g1043790009

DP-850SHの写真では説明書表紙に `DP-850SH / DP-1020SH` とあり、その横の付属リモコンが `RRMCG2009SCZZ` と同一外観。DP-1020SHの写真でも同一外観のリモコンが本体付属品として写る。

### 確定度: 中 — 流通個体で `RRMCG2009SCZZ` が DP-850SH / DP-1020SH 用と明記

2026年に確認できる中古出品では、`RRMCG2009SCZZ` の商品説明に `DP-850SH DP-1020SH` と明記された例がある。

- https://jp.mercari.com/item/m93734607492
- https://jp.mercari.com/item/m53512993273

これはメーカー一次資料ではなく販売者による適合表記なので、それ単独では公式対応表として扱わない。ただし上記の実機一式写真と整合する。

## 現時点で言えること

### 確定事項

- DP-700SH純正リモコンの型番は `RRMCG2009SCZZ`（既確認）。
- DP-850SH / DP-1020SH の実機一式写真には、`RRMCG2009SCZZ` と前面形状・キー配置が一致するFUJIFILMリモコンが付属している。

### 強い状況証拠

- `RRMCG2009SCZZ` は DP-700SH だけでなく、2010年の DP-850SH / DP-1020SH でも共通リモコンとして使われた可能性が高い。
- したがって3機種でリモコン受信側のプロトコル／コマンド体系が共通である可能性も高まる。これは、同日同内容のファーム修正、共通のIrSimple/IrSS機能、共通したUI系統と整合する。

### まだ断定しないこと

- DP-850SH / DP-1020SH のリモコン裏面ラベルを今回の一式写真から直接読めたわけではないため、「両機種の公式付属型番が必ず RRMCG2009SCZZ」とまでは一次資料で確定していない。
- 同じリモコン外観・型番だったとしても、赤外線の搬送波、方式、アドレス、各キーコードは未回収。
- 3機種のリモコン共通性だけではSoCやメイン基板の同一性は証明できない。

## リバースエンジニアリング上の意味

DP-850SH / DP-1020SH の中古個体やリモコンから信号を学習できれば、DP-700SH実機向けの赤外線コード探索にそのまま利用できる可能性がある。特に、3機種共通リモコンであることが確定すれば、DP-700SH単体に限定せず流通数の多いDP-850SH / DP-1020SH付属品も信号採取対象にできる。
