# DP-700SH 調査ログ — 2026-09-20 09:39 JST

## Sharp側ソフトウェア基盤を再探索

Sharpが2008〜2010年に開発したデジタル写真機器を、DP-700SHとの機能共通性を軸に検索。

### 発見

イーソルの2009-05-12プレスリリースで、Sharp開発のAQUOSフォトプレーヤー `HN-PP100` / `HN-PP150` にeCROS採用を確認。

公開された構成:
- RTOS: μITRON4.0準拠 `PrKERNELv4`
- `eBinder`
- ファイルシステム
- SD/MS等メディアドライバ
- USBホストスタック

HN-PP100のSharp公式仕様を照合すると、SD/MS + CF + USB + IrSS + 専用IRリモコン + 写真スライドショーを備える。DP-70SH/700SH系列とかなり近い周辺I/O構成。

### ファームウェア命名の追加発見

Sharp公式HN-PP150更新手順で更新ファイル名 `TH150400.ver` を確認。公式配布ページでは121MB。

既知のDP-70SH `TH180700.ver` と `TH*.ver` 命名が一致するため、`TH` 接頭辞がFUJIFILM独自ではなくSharp側のデジタル写真機器でも実在することが分かった。

DP-700SH世代の `TH34_dpf.pkg` 等は拡張子が異なるため、同一更新器・同一コンテナ形式とは断定しない。

### OS仮説の更新

これまでOS固有名は不明だったが、**eCROS / PrKERNELv4 を具体的な比較候補に追加**する。

直接証拠ではないので確定扱いにはしない。特に、Sharpが製造元であること、周辺I/Oが似ること、`TH`命名が似ることだけではDP-700SHへのeCROS採用を証明できない。
