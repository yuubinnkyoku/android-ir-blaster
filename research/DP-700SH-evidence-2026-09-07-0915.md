# DP-700SH 調査追補 — 2026-09-07 09:15 JST

## 今回の新規根拠

### 確定事項: 先代 DP-70SH の公式ファームには gzip/DEFLATE 展開処理とシリアルフラッシュ制御が組み込まれている

Wayback Machine に保存されている FUJIFILM 公式配布ファイル `TH180700.ver`（DP-70SH Ver.1.07.00）を生バイナリとして再確認した。

保存実体:
- https://web.archive.org/web/20160623113110id_/http://download.fujifilm.co.jp/pub/tools/dp70sh/TH180700.ver

バイナリ中には、以前確認済みの `SHARP_PF100_PLATFORM` に加え、次の文字列が存在する。

- `gz_size %x`
- `deflated`
- `fwz_index`
- `NEW SERIAL FLASH`
- `MXIC`
- `ATMEL`
- `erase %x`
- `prog`
- `wait`
- `FIRMWARE`
- `VERSION`
- `CHECKSUM`
- `BOOT`
- `NVRAM`
- `NVRAM_2`
- `ROMTAB`
- `STRTAB`

また、同じ領域には `main clk %d`、USB Device 制御のデバッグ文字列、`FW Revision: V%d.%02d` などもある。

これにより少なくとも DP-70SH の Sharp PF100 系ソフトウェアには、

1. gzip/DEFLATE 系データを展開する処理
2. シリアルフラッシュの識別・消去・書込み処理
3. BOOT / NVRAM / FIRMWARE / VERSION / CHECKSUM 等を扱う更新・起動関連処理

が含まれることを直接確認できる。

### 確定事項: シリアルフラッシュ制御コードは Atmel / Macronix(MXIC) 系を識別する分岐を持つ

`TH180700.ver` 内のフラッシュ制御用とみられるデバッグ文字列には `ATMEL` と `MXIC` が現れ、周辺に `Unknown` / `Unsupported` / ID・page・erase/program 関連文字列が並ぶ。

したがって、PF100 系のフラッシュドライバが少なくとも Atmel と Macronix(MXIC) 系シリアルフラッシュを識別・処理するコードを持つことは高確度である。

**ただし、DP-70SH 実機に搭載されたフラッシュが Atmel/MXIC のどちらかであることは未確定。** 複数ベンダー対応の汎用ドライバである可能性がある。

### 状況証拠: `.ver` は単純な生ROMイメージではなく、更新コンテナ＋展開/書込み処理を含む可能性が高い

`TH180700.ver` にはコード本体、デバッグ文字列、`BOOT/NVRAM/FIRMWARE/VERSION/CHECKSUM` の区画名、gzip/DEFLATE 関連文字列が同居する。末尾付近には `RT` を含む表形式データや区画記述らしき構造も見える。

このため、少なくとも「単一の無加工ROMダンプをそのまま書く」形式ではなく、複数区画・検査・展開を伴う Sharp 独自更新形式である可能性が高い。

ただし、現時点ではヘッダ形式、各区画のオフセット/長さ、圧縮範囲、チェックサム方式は未確定。

## DP-700SH への意味

DP-700SH/850SH/1020SH は 2010 年に `TH34_dpf.pkg` / `TH35_dpf.pkg` / `TH36_dpf.pkg` へ更新形式が切り替わっている。今回の新情報は `.pkg` の中身を直接示さないが、Sharp の直前世代 PF100 系ですでに

- 圧縮データ展開
- シリアルフラッシュ更新
- 区画名・バージョン・チェックサム管理

が存在したことを示す。

したがって `.pkg` 解析時には、単なるZIP/TAR探索だけでなく、**Sharp独自ヘッダ + DEFLATE圧縮 + フラッシュ区画記述**の系譜を優先候補として見る価値が上がった。

## 推測（未確定）

- DP-700SH の 2010 世代も PF100 の更新/フラッシュ管理コードの一部を継承している可能性がある。
- `TH34_dpf.pkg` のペイロードにも DEFLATE 系圧縮または類似の区画テーブルが使われている可能性がある。
- DP-700SH の基板にも SPI NOR 等のシリアルフラッシュが存在する可能性が高いが、基板写真/SoC資料による直接確認はまだない。

## 断定しないこと

- `ATMEL` / `MXIC` 文字列だけから実装フラッシュメーカーを断定しない。
- `SHARP_PF100_PLATFORM` が DP-700SH のプラットフォーム名であるとは断定しない。
- gzip/DEFLATE 文字列だけから `TH34_dpf.pkg` の圧縮方式を断定しない。
