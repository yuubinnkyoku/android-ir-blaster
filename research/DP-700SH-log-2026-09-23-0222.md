## New finding

Digital Camera Watch (2009-04-01) preserves the exact DP-70SH firmware updater entry procedure: on the version-information screen, use the remote in the order `拡大 → 縮小 → 時計 → 回転`; the device then changes to the firmware rewrite screen. Firmware is supplied via formatted SD card.

Source:
- https://dc.watch.impress.co.jp/cda/accessories/2009/04/01/10602.html

A DP-70SH hands-on review confirms the model is FUJIFILM's first digital photo frame and reiterates Sharp ASV 800×480 + IrSimple:
- https://dc.watch.impress.co.jp/cda/item/2009/05/08/10786.html

## Assessment

Confirmed only for DP-70SH. It is not evidence that DP-700SH uses the same SoC/OS/updater. However, DP-700SH has the same four remote functions and a `本体情報の表示` screen, making this an unusually concrete compatibility test. If DP-700SH responds, it would materially strengthen software-platform continuity from DP-70SH to DP-700SH.
