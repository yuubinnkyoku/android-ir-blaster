# DP-700SH 調査追補 — 2026-09-06 18:48 JST

## 今回の新しい根拠

### 確定事項: 直系前世代 DP-70SH のファーム書き換え画面はリモコンの隠しキー列で開く

デジカメ Watch の 2009-04-01 の記事に、FUJIFILM DP-70SH の Ver.1.04.00 ファームウェア更新手順が具体的に残っている。

`設定メニュー` → `本体情報の表示` → `バージョン表示` を表示した状態で、純正リモコンを

`拡大` → `縮小` → `時計` → `回転`

の順に押すと **「ファームウェア書き換え画面」へ移行する**。

出典:
- https://dc.watch.impress.co.jp/cda/accessories/2009/04/01/10602.html

DP-70SH は 2009 年発売の FUJIFILM 初代デジタルフォトフレームで、Sharp ASV 液晶、800×480、IrSimple、CF/SD/MS/xD、miniUSB 系統など、後継 DP-700SH とかなり近い構成を持つ。

参考:
- https://dc.watch.impress.co.jp/cda/item/2009/05/08/10786.html
- https://www.itmedia.co.jp/news/article/0902/04/1090204098/

### 状況証拠: DP-700SH のリモコン探索に使える「既知の4キー集合」が得られた

DP-700SH 純正リモコン `RRMCG2009SCZZ` の前面にも `拡大` / `縮小` / `時計` / `回転` の4キーが存在することは既に実物写真から確認済み。

したがって、DP-70SH と DP-700SH の間では、少なくとも操作語彙とファーム更新時のサービス操作設計が継承された可能性がある。

これは赤外線総当たり探索で特に有用で、未知の全キーを一度に特定する必要はなく、まず `拡大` / `縮小` / `時計` / `回転` に相当する4コードを候補として確保できれば、DP-700SHでも同じ書き換え画面呼出し列が残っているかを検証できる。

### 状況証拠: DP-1020SH 実物セット写真でも同系統のリモコン外形・キー配置を確認

中古流通の DP-1020SH 実物セット写真では、付属リモコン前面が DP-700SH の `RRMCG2009SCZZ` と同系統の外形・主要キー配置に見える。`メニュー`、方向/決定、戻る、スライドショー、時計、縮小、拡大、回転などの配置が一致する。

出典:
- https://jp.mercari.com/shops/product/cd4YWwLhLCNJNXCn6pVCoQ

ただし当該写真ではリモコン裏面型番を読めないため、**DP-1020SH のリモコン型番そのものが RRMCG2009SCZZ と同一だとはまだ確定しない**。

## 推測

- DP-70SH → DP-700SH → DP-850SH/DP-1020SH で、ユーザーインターフェイスとリモコン処理の相当部分が共通化・継承されている可能性がある。
- DP-700SH でも `本体情報の表示` 中に `拡大→縮小→時計→回転` を送ることでサービス/ファーム更新画面へ入れる可能性がある。
- もし再現すれば、DP-70SH と DP-700SH のソフトウェア系譜を示すかなり強い実機証拠になる。

## 断定禁止

- DP-70SH と DP-700SH の SoC が同じとは言えない。
- DP-70SH と DP-700SH の赤外線コード値が同一とはまだ言えない。
- DP-1020SH の付属リモコン型番が `RRMCG2009SCZZ` と同一とは、裏面型番が未確認なので断定しない。
- DP-700SH で同じ隠しキー列が動作することも、現時点では未検証。
