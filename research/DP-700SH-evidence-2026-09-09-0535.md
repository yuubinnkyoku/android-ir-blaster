# DP-700SH 調査追補 — 2026-09-09 05:35 JST

## 新規根拠: 先代 DP-70SH の隠しファームウェア書換え画面への操作列

### 確定事項

2009-03-31、FUJIFILM は先代 7型デジタルフォトフレーム `DP-70SH` のファームウェア `Ver.1.04.00` を公開した。当時のデジカメ Watch の記事には、更新手順として次の操作が具体的に記録されている。

1. フォーマット済み SD メモリーカードにファームウェアを保存する。
2. `設定メニュー` → `本体情報の表示` → `バージョン表示` を表示する。
3. リモコンで **`拡大` → `縮小` → `時計` → `回転`** の順に押す。
4. **ファームウェア書き換え画面に切り替わる。**

出典:
- デジカメ Watch「富士フイルム、7型デジタルフォトフレームのファームウェアを公開」(2009-04-01)
  - https://dc.watch.impress.co.jp/cda/accessories/2009/04/01/10602.html
- 記事中に残る当時のFUJIFILM更新ページURL
  - http://fujifilm.jp/support/printer/download/digitalphotoframe/dp70sh/download001.html

同記事から、DP-70SHは以下を備えることも再確認できる。

- 7型 800×480 SHARP ASV液晶
- 明るさセンサー
- IrSimple
- SDメモリーカードを利用したファームウェア更新

DP-70SHの公開更新版のバージョン番号は **`1.04.00`**。

### DP-700SHとの接続 — 状況証拠

DP-700SHも、手元実機で `各種設定／本体情報の表示` にバージョン表示が存在することを確認済みであり、公式更新版も `Ver.1.04.00`。2010年更新はSDカードへ `TH34_dpf.pkg` を保存して適用する方式だったことも確認済み。

さらにDP-70SHとDP-700SHは、7型800×480のSHARP ASV液晶、明るさセンサー、IrSimple/IrSS系の画像転送、リモコン操作という主要構成が近い。

以上から、**DP-700SHでも「本体情報の表示」画面からリモコンの特定キー列で書換え画面へ入る保守経路が継承されている可能性**は十分ある。

特に、まず実機で試す候補として `拡大 → 縮小 → 時計 → 回転` を優先する価値が高い。

### 断定禁止 / 未確認

- `拡大 → 縮小 → 時計 → 回転` が **DP-700SHでも有効**だという直接証拠はまだない。
- DP-70SHとDP-700SHが同じSoC、同じOS、同じブートローダ、同じファームウェア形式だった証拠はない。
- DP-70SHの更新ファイル名・実バイナリは今回未回収。
- `DP-70SH Ver.1.04.00` と `DP-700SH Ver.1.04.00` は番号が同じだが、同一コードベースや同一ビルドを意味するとは限らない。

## リバースエンジニアリング上の意味

DP-700SHでこの操作列が通れば、純正 `TH34_dpf.pkg` をまだ回収できていなくても、書換え画面の文言、要求ファイル名、媒体スキャン挙動、エラー表示などから追加情報を得られる可能性がある。

一方で、書換え開始を確定する操作は不用意に実行せず、まず画面遷移と表示内容の記録を優先する。
